## Concept Explanation
**Exploratory Data Analysis (EDA)** is a critical phase in the data science lifecycle that occurs after data cleaning but before formal modeling. 
*   **Purpose:** Its main goal is to "look at" the data to understand its internal structure, detect outliers, and identify relationships between variables that aren't immediately obvious.
*   **Tools:** It relies heavily on **Visualization** (histograms, scatter plots, box plots) and **Descriptive Statistics** (mean, median, standard deviation, correlation matrices).
*   **Impact on ML:** EDA is not just about looking at pictures; it directly influences the next steps. By understanding the data distribution, a practitioner can decide which features to create (**Feature Engineering**) and which algorithm is best suited for the data's characteristics (**Model Selection**).

## Exam / Viva Points
*   **Definition:** EDA stands for Exploratory Data Analysis; it is the process of analyzing datasets to summarize their main characteristics, often with visual methods.
*   **Hidden Insights:** EDA is used to uncover patterns and trends that are "not visible to the naked eye" through raw data inspection.
*   **Four Key Features:**
    1.  **Exploration:** Using stats and visuals.
    2.  **Patterns/Trends:** Finding underlying structures and data challenges (like missing values or outliers).
    3.  **Insights:** Generating knowledge to guide future steps.
    4.  **Decision Making:** Specifically informing feature engineering and model selection.
*   **Downstream Effects:** A student should be able to explain that a poor EDA often leads to poor model performance because the features chosen might not represent the underlying data patterns correctly.
