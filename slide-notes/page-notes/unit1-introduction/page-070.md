## Concept Explanation
This slide outlines the four pillars of pattern recognition:

1.  **Template Matching:** This is the most intuitive approach. An unknown input pattern is directly compared against a set of pre-defined "templates" or prototypes stored in memory. The system identifies the pattern by finding the template that matches the input most closely based on a similarity measure (like pixel-by-pixel comparison).
2.  **Statistical Pattern Recognition:** This approach treats patterns as points in a high-dimensional feature space. It assumes that patterns are generated by a probabilistic process. Classification is performed by building statistical models (like probability density functions) for each class and using decision boundaries to separate them.
3.  **Structural (or Syntactic) Pattern Recognition:** Instead of just looking at global features, this method looks at the internal structure. It views complex patterns as being composed of simpler sub-patterns called "primitives." The relationships between these primitives are defined using formal rules, much like the grammar of a language (hence "syntactic"). Tools like strings, trees, and automata are used to represent these structures.
4.  **Neural Networks:** This is a "connectionist" approach inspired by the biological structure of the human brain. It uses a network of interconnected artificial neurons (cells). The "knowledge" of the classifier is not explicitly programmed but is learned by adjusting the weights of the connections between these neurons during a training phase.

## Exam / Viva Points
*   **List the four main models of pattern recognition:** Template matching, Statistical, Structural (Syntactic), and Neural Networks.
*   **Define Statistical Pattern Recognition:** It is based on the underlying statistical models of patterns and their classes, often involving probability distributions.
*   **Explain the core concept of Structural Pattern Recognition:** It represents patterns through formal structures like grammars, strings, and automata, focusing on how sub-patterns (primitives) relate to each other.
*   **What is the "connectionist approach"?** This refers to Neural Networks, where the classifier is modeled as a network of interconnected cells mimicking biological neurons.
*   **Contrast Template Matching with Structural Recognition:** Template matching is a direct holistic comparison, while structural recognition breaks a pattern down into its constituent parts and their arrangement.
