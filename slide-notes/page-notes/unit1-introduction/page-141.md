## Concept Explanation
The slide introduces **Linear Discriminant Analysis (LDA)**, a fundamental technique in statistical learning.
*   **Supervised Learning:** Unlike PCA (Principal Component Analysis), which is unsupervised, LDA uses the class labels of the training data. It "knows" which category each data point belongs to.
*   **Dual Purpose:**
    *   **Classification:** It can be used to build a model that predicts the class of new, unseen data points.
    *   **Dimensionality Reduction:** It reduces the number of features (variables) in a dataset while preserving as much class-discriminatory information as possible. This is useful for data visualization and improving the efficiency of other algorithms.
*   **Core Objective:** The goal is to project data from a high-dimensional space onto a lower-dimensional space. In doing so, it seeks to maximize the distance between the means of different classes (between-class variance) and minimize the spread within each class (within-class variance). This results in a "linear combination of features" that provides the clearest separation between groups.
