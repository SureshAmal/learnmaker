## Concept Explanation
This slide describes the **Reinforcement Learning (RL) Loop**. Reinforcement learning is a branch of machine learning where an **Agent** learns to make decisions by performing actions in an **Environment** to achieve a goal.

1.  **Observation (State $s_t$):** The agent looks at the current situation. For example, in a game of chess, the state is the current position of all pieces on the board.
2.  **Action ($a_t$):** Based on its current strategy (policy), the agent chooses a move.
3.  **Transition (New State $s_{t+1}$):** The environment changes as a result of the action. In chess, the board state changes after a piece is moved.
4.  **Feedback (Reward $r_t$):** The environment provides feedback. A positive reward encourages the behavior, while a penalty (negative reward) discourages it.
5.  **Optimization (Learning):** The agent uses the feedback to update its internal logic. The ultimate goal is to maximize the total cumulative reward over time.

## Exam / Viva Points
*   **The Five Steps:** Be prepared to list the five steps of the RL process in order: Observation $\rightarrow$ Action $\rightarrow$ State Change $\rightarrow$ Reward $\rightarrow$ Learning.
*   **Agent vs. Environment:** Understand that the Agent is the learner/decision-maker, and the Environment is everything the agent interacts with.
*   **Role of Reward:** Explain that the reward signal is the primary way the agent knows if its actions are successful or not.
*   **Iterative Nature:** Emphasize that this is a continuous loop; the agent repeats these steps thousands or millions of times to master a task.
