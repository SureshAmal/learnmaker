## Concept Explanation
*   **Linear Discriminant Analysis (LDA):** This is a method used in statistics and machine learning to find a linear combination of features that characterizes or separates two or more classes of objects.
*   **Supervised Dimensionality Reduction:** Unlike Principal Component Analysis (PCA), which is unsupervised, LDA is **supervised**. This means it uses the class labels of the data to find the projection that maximizes the distance between the means of different classes while minimizing the variance within each class.
*   **Fisher's Linear Discriminant:** This is the mathematical foundation upon which LDA is built. It specifically refers to the criterion used to find the optimal projection.
*   **Goal of the Classifier:** The ultimate objective is to project high-dimensional data onto a lower-dimensional space (dimensionality reduction) in a way that makes the classes as distinct as possible for classification purposes.

## Exam / Viva Points
