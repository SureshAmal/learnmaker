## Concept Explanation
**Unsupervised Learning** is a branch of machine learning that deals with unlabeled data. 

*   **The Core Difference:** In Supervised Learning, the machine is given a "cheat sheet" (labels) that tells it the correct answer for every input. In Unsupervised Learning, there are no labels. The machine is given raw data and must figure out the relationships within that data by itself.
*   **Objectives:**
    *   **Patterns:** Identifying recurring sequences or trends within the dataset.
    *   **Structures:** Discovering the underlying mathematical or logical organization of the data (e.g., the distribution of data points in a high-dimensional space).
    *   **Groupings (Clustering):** Automatically sorting data points into groups based on similarities. For example, a model might group customers based on purchasing habits without being told what those groups should be (e.g., "big spenders" vs. "bargain hunters").
