## Concept Explanation
The slide explains **Unsupervised Learning**, a category of machine learning where the model is trained on data without human-provided labels.

*   **No Labels:** In supervised learning, you have input ($X$) and output ($Y$). In unsupervised learning, you only have input ($X$). The machine is not told what the "correct" answer is.
*   **Goal (Pattern Discovery):** The algorithm's job is to explore the data and find underlying structures. It looks for things that are similar to each other or things that stand out as different.
*   **Key Tasks:**
    *   **Clustering:** The process of partitioning a data set into groups (clusters) such that members of a group are more similar to each other than to members of other groups. *Example: A business grouping its customer base into "high-spenders" vs. "bargain hunters" based on purchase history.*
    *   **Dimensionality Reduction:** A technique to reduce the number of input variables in a dataset. This is done to simplify the model, reduce computational costs, and help visualize high-dimensional data in 2D or 3D while keeping the most important information.
    *   **Anomaly Detection:** Identifying rare items, events, or observations which raise suspicions by differing significantly from the majority of the data. *Example: Detecting a fraudulent credit card transaction that doesn't fit a user's normal spending pattern.*

## Exam / Viva Points
*   **Definition:** Unsupervised learning is a type of machine learning that looks for previously undetected patterns in a data set with no pre-existing labels and with a minimum of human supervision.
*   **Key Difference:** Unlike supervised learning, there is no "teacher" or "ground truth" to guide the learning process.
*   **Primary Objective:** To find the intrinsic structure or distribution in the data.
