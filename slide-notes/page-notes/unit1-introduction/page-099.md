## Concept Explanation
In machine learning, "Pattern Representation" is the process of converting raw data into a structured format that an algorithm can interpret.
1.  **Vector:** This is the standard representation for most machine learning models. Data is treated as a point in a $d$-dimensional space where each dimension is a specific feature (e.g., height, weight, age).
2.  **Graph:** Used when the relationships between data points are the primary focus. For example, in a social network, individuals are nodes, and their friendships are edges.
3.  **Strings:** Essential for sequential data where the order of elements is critical. This is the primary representation for Natural Language Processing (NLP) and bioinformatics (DNA/Protein sequences).
4.  **Trees:** Used for data that has a nested or parent-child structure. Examples include organizational charts, file systems, or the grammatical structure of a sentence (parse trees).
