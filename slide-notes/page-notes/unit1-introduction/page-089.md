## Concept Explanation
This slide covers the transition from traditional machine learning (where humans define features) to deep learning (where the machine learns features).

1.  **Automated Representation:** In deep learning, the model itself decides which characteristics of the data are important for the task (e.g., classification).
2.  **Tensors:** This is the mathematical language of deep learning. Data is stored in multi-dimensional arrays. A 2D image is a matrix (height x width), while a video adds a time dimension, making it a 3D tensor.
3.  **Latent Spaces:** As data moves through the hidden layers of a neural network, it is transformed into a "latent space." This is a compressed version of the data that captures its essential features while discarding noise.
4.  **Hierarchical Learning:** This is the "Deep" in Deep Learning. The network learns in stages:
    *   **Low-level layers:** Detect simple patterns like edges or color gradients.
    *   **Mid-level layers:** Combine edges into shapes or parts (e.g., eyes, nose).
    *   **High-level layers:** Combine parts into complex objects (e.g., a whole face).
