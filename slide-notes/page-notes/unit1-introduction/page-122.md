## Concept Explanation
This slide introduces the fundamental "toolbox" of a data scientist. Machine learning is not a single algorithm but a collection of techniques categorized by the nature of the output and the structure of the data:
*   **Classification:** A supervised learning task where the goal is to assign an input to one of several predefined classes (e.g., classifying an email as "spam" or "not spam").
*   **Regression:** A supervised learning task where the goal is to predict a continuous quantity (e.g., predicting the price of a house based on its square footage).
*   **Clustering:** An unsupervised learning task where the goal is to find natural groupings in data without any prior labels (e.g., segmenting customers based on purchasing behavior).
*   **Dimensionality Reduction (Dim. Reduction):** A technique used to reduce the number of input variables in a dataset. This helps in visualization, reducing noise, and speeding up other ML algorithms.
*   **Deep Learning:** A specialized subfield of ML that uses multi-layered neural networks to model complex relationships, particularly effective for unstructured data like images, text, and audio.

## Exam / Viva Points
*   **Classification vs. Regression:** Be able to explain that classification predicts labels/categories while regression predicts continuous numbers.
*   **Unsupervised Learning Examples:** Identify Clustering and Dimensionality Reduction as primary unsupervised tasks.
*   **Algorithm Identification:** If asked for a clustering algorithm, name K-Means or DBSCAN. If asked for a dimensionality reduction technique, name PCA or t-SNE.
*   **Deep Learning Architectures:** Know that CNNs are typically for images and RNNs are typically for sequential data like text or time series.
*   **Acronyms:** Be prepared to expand acronyms like SVM (Support Vector Machine), KNN (K-Nearest Neighbors), PCA (Principal Component Analysis), and CNN (Convolutional Neural Network).
