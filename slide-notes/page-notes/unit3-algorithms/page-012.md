## Concept Explanation
*   **Statistical Learning Theory:** This is a framework for machine learning that relies on statistics and functional analysis. It provides the theoretical basis for how machines can "learn" from data.
*   **Goals of Learning:**
    *   **Understanding:** Gaining insight into the nature of the data and the underlying process that generated it.
    *   **Prediction:** The ability to take new, unseen inputs and accurately forecast their corresponding outputs based on patterns learned from historical data.
*   **Learning Categories:**
    *   **Supervised:** Learning with labeled data (input-output pairs).
    *   **Unsupervised:** Finding hidden structures in unlabeled data.
    *   **Online:** Learning continuously as data arrives in a stream.
    *   **Reinforcement:** Learning through trial and error to maximize a reward signal.
*   **The Learning Problem:** At its heart, machine learning is about **function approximation**. We have inputs ($X$) and outputs ($Y$). The goal is to "infer" (estimate) the hidden function that links them so we can use it for future, unknown $X$ values.

## Exam / Viva Points
*   **What are the two main goals of Statistical Learning?** Understanding the data generation process and predicting future outcomes.
*   **Define the "Learning Problem" in technical terms.** It is the process of inferring a mapping function between input and output variables.
*   **Name four categories of learning mentioned in the theory.** Supervised, Unsupervised, Online, and Reinforcement learning.
*   **Why is the "mapping function" important?** It allows the model to generalize from training data to make predictions on new, future inputs.
