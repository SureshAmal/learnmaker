## Concept Explanation
This slide introduces two critical phases in the machine learning workflow:

1.  **Evaluation:** This is the process of measuring how well a trained model performs. Since a model might perform perfectly on the data it has already seen (training data) but fail on new data, evaluation typically involves testing the model on a separate "test set." Common metrics include Accuracy, Precision, Recall, and F1-score for classification, or Mean Squared Error (MSE) for regression.
2.  **Model Selection:** This is the decision-making process of choosing the "best" model among several candidates. Candidates might be different types of algorithms (e.g., a Decision Tree vs. a Neural Network) or the same algorithm with different settings (hyperparameters). The goal is to select the model that generalizes best to unseen data, avoiding both underfitting and overfitting.

## Exam / Viva Points
*   **Definition of Evaluation:** Assessing a model's performance using specific metrics on a dataset it hasn't seen during training.
*   **Definition of Model Selection:** The process of comparing different models (or configurations) to find the one that provides the best predictive performance.
*   **Generalization:** The core goal of both evaluation and selection is to ensure the model performs well on real-world, unseen data, not just the training set.
*   **Metrics:** Be prepared to name metrics used for evaluation (e.g., Accuracy for classification, R-squared for regression).
