## Concept Explanation
In Machine Learning, **Discriminant Functions** are functions used to perform classification. They take an input vector (data) and assign it to one of $K$ discrete classes. The function essentially defines a "decision boundary" in the feature space.

The applications listed are all classic **Classification Problems**:
1.  **Face Recognition:** The system uses a discriminant function to classify an image of a face as belonging to a specific individual in a database.
2.  **Handwriting Digit Recognition:** A common benchmark (like the MNIST dataset) where the function must classify an image of a handwritten character into one of ten categories (digits 0 through 9).
3.  **Medical Diagnosis:** Based on patient features (symptoms, blood test results, imaging), the function classifies the patient's condition (e.g., "Healthy" vs. "Diseased" or identifying specific types of ailments).
4.  **Spam Detection:** A binary classification task where the function analyzes the content and metadata of an email to classify it as either "Spam" or "Ham" (legitimate email).

## Exam / Viva Points
