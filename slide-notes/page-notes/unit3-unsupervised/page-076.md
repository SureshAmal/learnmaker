## Concept Explanation
**Ensemble Learning** is a machine learning paradigm where multiple models (often called "base learners" or "weak learners") are trained to solve the same problem and then combined to produce a single, superior output.

The slide explains this through an analogy:
1.  **Individual Models (The Friends):** Each friend represents a different model. Each model has a specific "feature" or data source it focuses on (e.g., historical data, text analysis, or visual cues).
2.  **Weaknesses:** A single model might be biased or lack enough information to be perfectly accurate. For example, a trailer might be misleading, or past ratings might not account for a change in the director's style.
3.  **Aggregation:** By "combining their opinions" (which in ML could be done via averaging, voting, or stacking), the individual errors of the models tend to cancel each other out.
4.  **Result:** The final "ensemble" prediction is typically more robust and accurate than any of the individual predictions.

## Exam / Viva Points
*   **Definition:** Ensemble learning is the process of combining multiple models to improve the overall performance of a system.
*   **The "Wisdom of the Crowd":** The core principle is that a collective of diverse models will perform better than any single constituent model.
*   **Error Reduction:** Combining models helps reduce individual errors like high variance (overfitting) or high bias (underfitting).
*   **Diversity is Key:** For an ensemble to be effective, the individual models should ideally make different types of mistakes (they should be diverse).
