## Concept Explanation
This slide organizes the field of machine learning into a structured hierarchy:
*   **Statistical Learning Methods:** These are methods that use statistical theory to build models. They are categorized here by the nature of the data:
    *   **Complete Data:** When every feature and label in the dataset is known.
    *   **Hidden Data (EM Algorithm):** When some data is missing or unobserved (latent variables). The **Expectation-Maximization (EM)** algorithm is the standard tool used to find maximum likelihood estimates in these scenarios.
*   **Learning from Observations:**
    *   **Inductive Learning (EBL):** Moving from specific instances to a general rule.
    *   **Deductive Learning (RBL):** Using existing knowledge/rules to explain or categorize new instances.
*   **Ensemble Learning:** Techniques like Bagging or Boosting that combine multiple "weak" learners to create a "strong" learner.
*   **Reinforcement Learning (RL):** A paradigm where an agent learns to behave in an environment by performing actions and seeing the results (rewards or penalties).
