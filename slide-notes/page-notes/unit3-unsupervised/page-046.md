## Concept Explanation
*   **Linear Discriminant Analysis (LDA):** A classic statistical and machine learning method.
*   **Supervised Learning:** This means the algorithm learns from a training dataset where the correct answers (labels or classes) are already provided. It uses this knowledge to make predictions on new, unseen data.
*   **Classification:** The task of assigning a data point to a specific category (e.g., "spam" vs. "not spam"). LDA creates boundaries to decide which class a point belongs to.
*   **Dimensionality Reduction:** The process of reducing the number of input variables in a dataset. LDA does this by projecting high-dimensional data onto a lower-dimensional space while trying to keep the classes as distinct as possible.
*   **Linear Combination of Features:** LDA works by mathematically combining existing features (like height, weight, age) into a new single value (a "discriminant score") using a linear equation (e.g., $Score = w_1 \cdot \text{feature}_1 + w_2 \cdot \text{feature}_2$). The goal is to find the weights ($w$) that make the scores for different classes as different as possible.
