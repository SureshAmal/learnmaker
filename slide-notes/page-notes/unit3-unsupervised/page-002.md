## Concept Explanation
This slide introduces two fundamental pillars of the machine learning lifecycle:

1.  **Evaluating Machine Learning Algorithms:** Once a model is trained, it must be tested to see how well it performs. This involves using specific metrics (such as Accuracy, Precision, Recall, or Mean Squared Error) on a "test set"—data the model has never seen before. Evaluation helps determine if the model is useful or if it suffers from issues like overfitting (performing well on training data but poorly on new data).
2.  **Model Selection:** Often, data scientists try multiple algorithms (e.g., Logistic Regression vs. Decision Trees) or different configurations (hyperparameters) for the same algorithm. Model Selection is the systematic process of comparing these different versions to choose the one that provides the best predictive performance and generalization for the specific problem at hand.

## Exam / Viva Points
*   **Definition of Evaluation:** The process of assessing a model's performance using statistical metrics on unseen data.
*   **Definition of Model Selection:** The task of choosing the best-performing model from a set of candidate models.
*   **Importance of Generalization:** The primary goal of both evaluation and selection is to ensure the model generalizes well to real-world, unseen data, rather than just memorizing the training set.
