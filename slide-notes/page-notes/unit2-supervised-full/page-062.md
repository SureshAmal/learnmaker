## Concept Explanation
*   **Confusion Matrix:** In machine learning, specifically for supervised learning classification tasks, a confusion matrix is a summary of prediction results. It allows for the visualization of the performance of an algorithm.
*   **Classification Model Evaluation:** While simple "accuracy" tells you how often a model is right, it doesn't tell you *how* it is wrong. A confusion matrix breaks down errors into specific categories.
*   **Actual vs. Predicted:** The core of the matrix is the comparison between the "Ground Truth" (Actual values) and what the "AI Model" guessed (Predicted values).
*   **Binary Classification Example:** The slide uses "Spam vs. Not Spam," which is a classic binary classification problem. By using a fixed number (100 emails), the instructor prepares the student to calculate metrics like Precision, Recall, and Accuracy in subsequent slides.

## Exam / Viva Points
*   **Definition:** A confusion matrix is a performance measurement tool for machine learning classification problems where output can be two or more classes.
*   **Key Comparison:** It compares the **Actual Class** (target) against the **Predicted Class** (output of the model).
*   **Utility:** It is used to identify where the model is getting "confused"—for instance, if it is frequently mislabeling legitimate emails as spam (False Positives).
*   **Context:** It is essential for evaluating models on imbalanced datasets where simple accuracy might be misleading.
