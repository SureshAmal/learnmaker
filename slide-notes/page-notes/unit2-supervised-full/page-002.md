## Concept Explanation
*   **Regression:** A fundamental task in supervised machine learning. Unlike classification, which predicts discrete labels (like "Cat" or "Dog"), regression predicts a quantity on a continuous scale.
*   **Supervised Learning:** This means the algorithm is trained on a dataset that includes both the inputs and the correct answers (labels/targets).
*   **Features vs. Target:** 
    *   **Features (Input Variables):** The independent variables or data points used to make a prediction (e.g., square footage of a house, age of a car).
    *   **Target (Output Variable):** The dependent variable or the specific numerical value the model aims to predict (e.g., the price of the house, the current value of the car).
*   **Purpose:** Regression models the mathematical relationship between variables. By understanding how an input "factor" affects the "outcome," we can predict future values based on new input data.
*   **Applications:**
    *   **Forecasting:** Predicting future sales or weather patterns.
    *   **Risk Analysis:** Estimating the likelihood of financial loss or insurance claim amounts.
    *   **Trend Estimation:** Determining if a data series (like stock prices) is generally moving up or down over time.
