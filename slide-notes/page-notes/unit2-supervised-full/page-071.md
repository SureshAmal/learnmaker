## Concept Explanation
In machine learning, specifically binary classification (where the goal is to predict one of two classes, like "Spam" or "Not Spam"), there are four possible outcomes when comparing a model's prediction to the actual ground truth:

1.  **True Positive (TP):** The model correctly identifies the positive class. Example: A medical test correctly identifies a person who has a disease.
2.  **True Negative (TN):** The model correctly identifies the negative class. Example: A medical test correctly identifies a healthy person as not having the disease.
3.  **False Positive (FP):** Also known as a **Type I Error** or **False Alarm**. The model predicts the positive class, but the actual value is negative. Example: A smoke detector goes off when there is no fire.
4.  **False Negative (FN):** Also known as a **Type II Error** or **Missed Detection**. The model predicts the negative class, but the actual value is positive. Example: A security alarm fails to trigger during an actual break-in.

## Exam / Viva Points
*   **Definitions:** Be prepared to define all four terms (TP, TN, FP, FN) clearly.
*   **Synonyms:** Remember that a False Positive is a "False Alarm" (Type I Error) and a False Negative is a "Missed Detection" (Type II Error).
*   **Contextual Importance:** In an exam, you might be asked which error is worse. The answer depends on the domain. In cancer screening, a False Negative (missing the disease) is usually much more dangerous than a False Positive (a false alarm requiring more tests).
*   **Foundation for Metrics:** Understand that these four values are the inputs for calculating Accuracy, Precision, Recall (Sensitivity), and Specificity.
