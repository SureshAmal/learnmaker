## Concept Explanation
This slide introduces the core terminology used in supervised learning, specifically for regression tasks:

1.  **Independent Variable (Input/Feature):** This is the variable that is considered the "cause" or the predictor. In a machine learning model, this is the data we feed into the algorithm. In the example, "Hours Studied" is the independent variable because we can choose how much to study, and we want to see how it affects the outcome. It is typically denoted as $X$.
2.  **Dependent Variable (Output/Target):** This is the variable we are trying to predict or explain. Its value "depends" on the independent variable. In the example, the "Exam Score" is the dependent variable. It is typically denoted as $Y$.
3.  **Linear Regression Goal:** The fundamental goal of linear regression is to find a mathematical relationship (usually a straight line) that allows us to input a value for the independent variable and get a predicted value for the dependent variable.
