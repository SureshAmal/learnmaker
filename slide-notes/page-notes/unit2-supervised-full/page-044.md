## Concept Explanation
*   **Supervised Learning:** Linear Regression falls under supervised learning because it requires a dataset with known labels (the "ground truth") to train the model.
*   **Variables:**
    *   **Independent Variable ($X$):** Also known as the predictor or feature. This is the input used to make a prediction.
    *   **Dependent Variable ($Y$):** Also known as the target or response. This is the continuous value the model aims to predict.
*   **Linearity Assumption:** The model operates on the fundamental assumption that the relationship between the input ($X$) and output ($Y$) can be represented by a straight line. If the relationship is curved (non-linear), standard linear regression will perform poorly.
*   **Best-Fit Line:** The goal of the algorithm is to find the specific line that minimizes the vertical distance (residuals/errors) between all data points and the line itself.
*   **Continuous Values:** Unlike classification (which predicts categories like "Cat" or "Dog"), regression predicts numerical values on a continuous scale, such as stock prices, temperature, or height.

## Exam / Viva Points

*   **Prediction Type:** It is used for predicting **continuous** numerical values.
*   **Core Assumption:** It assumes a **linear relationship** exists between the input features and the target output.
*   **Mechanism:** It functions by calculating a **best-fit line** that minimizes the error across the dataset.
