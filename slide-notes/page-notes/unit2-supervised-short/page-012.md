## Math / Formula / Curve Notes
The formula shown is: **$h(x) = \beta_0 + \beta_1x$**

*   **$h(x)$**: This is the **Hypothesis Function**. It represents the predicted value (the output) for a given input $x$. The '$h$' stands for hypothesis.
*   **$x$**: The **Independent Variable** or input feature. This is the data point provided to the model to make a prediction.
*   **$\beta_0$ (Beta zero)**: The **y-intercept** or **bias term**. It represents the predicted value of $h(x)$ when the input $x$ is zero.
*   **$\beta_1$ (Beta one)**: The **slope** or **coefficient** of the independent variable. It determines how much the prediction $h(x)$ changes for every one-unit change in $x$.

## Concept Explanation
In Machine Learning, a **Hypothesis Function** is the mathematical model that the algorithm uses to approximate the relationship between inputs and outputs. 

In **Simple Linear Regression**, we assume this relationship is a straight line. The goal of the learning process is to find the "best" values for the parameters $\beta_0$ and $\beta_1$. Once these parameters are learned from training data, the hypothesis function can take any new input $x$ and calculate a predicted output $h(x)$. 

*   **Independent Variable ($x$):** The cause or the input (e.g., square footage of a house).
*   **Dependent Variable ($y$ or $h(x)$):** The effect or the output we want to predict (e.g., the price of the house).
*   **Linearity:** The formula $h(x) = \beta_0 + \beta_1x$ describes a straight line on a 2D graph, which is why it is called "linear" regression.
