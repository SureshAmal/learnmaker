## Concept Explanation
The slide explains the relationship between two types of variables in a supervised learning context, specifically for **Linear Regression**:

1.  **Independent Variable (Input):** This is the variable that is presumed to cause a change in another variable. In machine learning, it is the input feature (often denoted as $X$). In the example, "Hours Studied" is the independent variable because it is the factor being measured or manipulated to see its effect.
2.  **Dependent Variable (Output):** This is the variable being predicted or tested. Its value "depends" on the independent variable. In machine learning, this is the target or label (often denoted as $Y$). In the example, the "Exam Score" is the dependent variable.
3.  **Positive Correlation:** The text notes that as study hours increase, scores generally increase. This describes a positive linear relationship, which is what linear regression attempts to model mathematically.
4.  **Predictive Goal:** The core purpose of linear regression is to establish a functional relationship where the input ($X$) can be used to calculate a predicted output ($Y$).

## Exam / Viva Points
*   **Definition of Independent Variable:** The input factor that is controlled or observed to see its impact on an outcome.
*   **Definition of Dependent Variable:** The output factor that changes in response to the independent variable; it is the value we aim to predict.
*   **Scenario Identification:** Be prepared to identify $X$ and $Y$ in different scenarios (e.g., predicting house price based on square footage).
*   **Relationship Direction:** Understand that in this specific example, there is a positive correlation (both variables move in the same direction).
*   **Role of Linear Regression:** It is a method used to model the relationship between a scalar response (dependent variable) and one or more explanatory variables (independent variables).
