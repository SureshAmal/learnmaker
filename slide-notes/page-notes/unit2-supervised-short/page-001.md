## Concept Explanation
The slide introduces the core components of **Supervised Learning**, a branch of machine learning where models are trained on labeled data. The listed topics represent the fundamental building blocks for understanding how these models work:

*   **Regression:** A task where the model predicts a continuous numerical output (e.g., predicting house prices based on square footage).
*   **Cost Function:** A mathematical measure that quantifies how far off the model's predictions are from the actual targets. Training involves minimizing this function.
*   **Gradient Descent:** The standard optimization algorithm used to minimize the cost function by iteratively adjusting model parameters.
*   **Bias-Variance Tradeoff:** A central concept in model evaluation. It describes the tension between a model being too simple (high bias) versus being too sensitive to noise in the training data (high variance).
*   **Overfitting & Underfitting:** These describe model performance issues. Underfitting occurs when a model is too simple to learn the data; overfitting occurs when a model learns the training data "too well," including its noise, leading to poor performance on new data.
*   **Regularization:** A set of techniques (like L1 or L2) used to prevent overfitting by adding a penalty for model complexity to the cost function.
