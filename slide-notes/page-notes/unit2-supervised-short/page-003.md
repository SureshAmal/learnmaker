## Concept Explanation
Linear Regression is one of the most basic and widely used algorithms in **Supervised Machine Learning**. 

*   **Supervised Learning:** This means the algorithm learns from a dataset that contains both the input (features) and the correct output (labels).
*   **Variables:**
    *   **Dependent Variable ($Y$):** This is the target variable we are trying to predict (e.g., the price of a house). It "depends" on other factors.
    *   **Independent Variable ($X$):** These are the input features used to make the prediction (e.g., square footage, age of the house).
*   **Mechanism:** The algorithm attempts to find the "best-fit" straight line through the data points. This line minimizes the distance between the actual data points and the line itself.
*   **Prediction Type:** It is used for **Regression** tasks, meaning it predicts continuous numerical values (like temperature, price, or height) rather than discrete categories (like "cat" vs "dog").
*   **Assumption:** The core assumption is **linearity**—that a change in the independent variable results in a proportional change in the dependent variable.
