# Generics and reflection

Because the Common Language Runtime (CLR) has access to generic type information at run time, you can use reflection to obtain information about generic types in the same way as for nongeneric types. For more information, see [Generics in the Runtime](../ch7/9.html).

The [`Emit`](https://learn.microsoft.com/dotnet/api/system.reflection.emit) namespace also contains new members that support generics. See [How to: Define a Generic Type with Reflection Emit](https://learn.microsoft.com/dotnet/fundamentals/reflection/how-to-define-a-generic-type-with-reflection-emit).

For a list of the invariant conditions for terms used in generic reflection, see the [`IsGenericType`](https://learn.microsoft.com/dotnet/api/system.type.isgenerictype) property remarks:

- [`IsGenericType`](https://learn.microsoft.com/dotnet/api/system.type.isgenerictype): Returns true if a type is generic.
- [`GetGenericArguments`](https://learn.microsoft.com/dotnet/api/system.type.getgenericarguments): Returns an array of `Type` objects that represent the type arguments supplied for a constructed type, or the type parameters of a generic type definition.
- [`GetGenericTypeDefinition`](https://learn.microsoft.com/dotnet/api/system.type.getgenerictypedefinition): Returns the underlying generic type definition for the current constructed type.
- [`GetGenericParameterConstraints`](https://learn.microsoft.com/dotnet/api/system.type.getgenericparameterconstraints): Returns an array of `Type` objects that represent the constraints on the current generic type parameter.
- [`ContainsGenericParameters`](https://learn.microsoft.com/dotnet/api/system.type.containsgenericparameters): Returns true if the type or any of its enclosing types or methods contain type parameters for which specific types haven't been supplied.
- [`GenericParameterAttributes`](https://learn.microsoft.com/dotnet/api/system.type.genericparameterattributes): Gets a combination of `GenericParameterAttributes` flags that describe the special constraints of the current generic type parameter.
- [`GenericParameterPosition`](https://learn.microsoft.com/dotnet/api/system.type.genericparameterposition): For a `Type` object that represents a type parameter, gets the position of the type parameter in the type parameter list of the generic type definition or generic method definition that declared the type parameter.
- [`IsGenericParameter`](https://learn.microsoft.com/dotnet/api/system.type.isgenericparameter): Gets a value that indicates whether the current `Type` represents a type parameter of a generic type or method definition.
- [`IsGenericTypeDefinition`](https://learn.microsoft.com/dotnet/api/system.type.isgenerictypedefinition): Gets a value that indicates whether the current [`Type`](https://learn.microsoft.com/dotnet/api/system.type) represents a generic type definition, from which other generic types can be constructed. Returns true if the type represents the definition of a generic type.
- [`DeclaringMethod`](https://learn.microsoft.com/dotnet/api/system.type.declaringmethod): Returns the generic method that defined the current generic type parameter, or null if the type parameter wasn't defined by a generic method.
- [`MakeGenericType`](https://learn.microsoft.com/dotnet/api/system.type.makegenerictype): Substitutes the elements of an array of types for the type parameters of the current generic type definition, and returns a [`Type`](https://learn.microsoft.com/dotnet/api/system.type) object representing the resulting constructed type.

In addition, members of the [`MethodInfo`](https://learn.microsoft.com/dotnet/api/system.reflection.methodinfo) class enable run-time information for generic methods. See the [`IsGenericMethod`](https://learn.microsoft.com/dotnet/api/system.reflection.methodbase.isgenericmethod) property remarks for a list of invariant conditions for terms used to reflect on generic methods:

- [`IsGenericMethod`](https://learn.microsoft.com/dotnet/api/system.reflection.methodbase.isgenericmethod): Returns true if a method is generic.
- [`GetGenericArguments`](https://learn.microsoft.com/dotnet/api/system.reflection.methodinfo.getgenericarguments): Returns an array of Type objects that represent the type arguments of a constructed generic method or the type parameters of a generic method definition.
- [`GetGenericMethodDefinition`](https://learn.microsoft.com/dotnet/api/system.reflection.methodinfo.getgenericmethoddefinition): Returns the underlying generic method definition for the current constructed method.
- [`ContainsGenericParameters`](https://learn.microsoft.com/dotnet/api/system.reflection.methodbase.containsgenericparameters): Returns true if the method or any of its enclosing types contain any type parameters for which specific types haven't been supplied.
- [`IsGenericMethodDefinition`](https://learn.microsoft.com/dotnet/api/system.reflection.methodbase.isgenericmethoddefinition): Returns true if the current [`MethodInfo`](https://learn.microsoft.com/dotnet/api/system.reflection.methodinfo) represents the definition of a generic method.
- [`MakeGenericMethod`](https://learn.microsoft.com/dotnet/api/system.reflection.methodinfo.makegenericmethod): Substitutes the elements of an array of types for the type parameters of the current generic method definition, and returns a [`MethodInfo`](https://learn.microsoft.com/dotnet/api/system.reflection.methodinfo) object representing the resulting constructed method.
