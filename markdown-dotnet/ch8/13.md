# Quantifier operations in LINQ (C#)

Quantifier operations return a [`Boolean`](https://learn.microsoft.com/dotnet/api/system.boolean) value that indicates whether some or all of the elements in a sequence satisfy a condition.

> **\1**
>
>
> These samples use an [`System.Collections.Generic.IEnumerable`](https://learn.microsoft.com/dotnet/api/system.collections.generic.ienumerable) data source. Data sources based on [`System.Linq.IQueryProvider`](https://learn.microsoft.com/dotnet/api/system.linq.iqueryprovider) use [`System.Linq.IQueryable`](https://learn.microsoft.com/dotnet/api/system.linq.iqueryable) data sources and [expression trees](../ch11/9.html). Expression trees have [limitations](../ch11/9.html#limitations) on the allowed C# syntax. Furthermore, each `IQueryProvider` data source, such as [EF Core](/ef/core/querying/complex-query-operators) may impose more restrictions. Check the documentation for your data source.

The following illustration depicts two different quantifier operations on two different source sequences. The first operation asks if any of the elements are the character 'A'. The second operation asks if all the elements are the character 'A'. Both methods return `true` in this example.

## All <a class="anchor" href="#all" id="all">#</a>
The following example uses the `All` to find students that scored above 70 on all exams.

> **\1**
>
> You can refer to the common data sources for this area in the [Standard Query Operators Overview](../ch8/8.html) article.


```csharp
IEnumerable<string> names = from student in students
                            where student.Scores.All(score => score > 70)
                            select $"{student.FirstName} {student.LastName}: {string.Join(", ", student.Scores.Select(s => s.ToString()))}";

foreach (string name in names)
{
    Console.WriteLine($"{name}");
}

// This code produces the following output:
//
// Cesar Garcia: 71, 86, 77, 97
// Nancy Engström: 75, 73, 78, 83
// Ifunanya Ugomma: 84, 82, 96, 80
```


## Any <a class="anchor" href="#any" id="any">#</a>
The following example uses the `Any` to find students that scored greater than 95 on any exam.


```csharp
IEnumerable<string> names = from student in students
                            where student.Scores.Any(score => score > 95)
                            select $"{student.FirstName} {student.LastName}: {student.Scores.Max()}";

foreach (string name in names)
{
    Console.WriteLine($"{name}");
}

// This code produces the following output:
//
// Svetlana Omelchenko: 97
// Cesar Garcia: 97
// Debra Garcia: 96
// Ifeanacho Jamuike: 98
// Ifunanya Ugomma: 96
// Michelle Caruana: 97
// Nwanneka Ifeoma: 98
// Martina Mattsson: 96
// Anastasiya Sazonova: 96
// Jesper Jakobsson: 98
// Max Lindgren: 96
```


## Contains <a class="anchor" href="#contains" id="contains">#</a>
The following example uses the `Contains` to find students that scored exactly 95 on an exam.


```csharp
IEnumerable<string> names = from student in students
                            where student.Scores.Contains(95)
                            select $"{student.FirstName} {student.LastName}: {string.Join(", ", student.Scores.Select(s => s.ToString()))}";

foreach (string name in names)
{
    Console.WriteLine($"{name}");
}

// This code produces the following output:
//
// Claire O'Donnell: 56, 78, 95, 95
// Donald Urquhart: 92, 90, 95, 57
```
