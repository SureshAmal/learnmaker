# Compiler-generated exceptions

Some exceptions are thrown automatically by the .NET runtime when basic operations fail. These exceptions and their error conditions are listed in the following table.

|Exception|Description|
|---------------|-----------------|
|[`ArithmeticException`](https://learn.microsoft.com/dotnet/api/system.arithmeticexception)|A base class for exceptions that occur during arithmetic operations, such as [`DivideByZeroException`](https://learn.microsoft.com/dotnet/api/system.dividebyzeroexception) and [`OverflowException`](https://learn.microsoft.com/dotnet/api/system.overflowexception).|
|[`ArrayTypeMismatchException`](https://learn.microsoft.com/dotnet/api/system.arraytypemismatchexception)|Thrown when an array can't store a given element because the actual type of the element is incompatible with the actual type of the array.|
|[`DivideByZeroException`](https://learn.microsoft.com/dotnet/api/system.dividebyzeroexception)|Thrown when an attempt is made to divide an integral value by zero.|
|[`IndexOutOfRangeException`](https://learn.microsoft.com/dotnet/api/system.indexoutofrangeexception)|Thrown when an attempt is made to index an array when the index is less than zero or outside the bounds of the array.|
|[`InvalidCastException`](https://learn.microsoft.com/dotnet/api/system.invalidcastexception)|Thrown when an explicit conversion from a base type to an interface or to a derived type fails at run time.|
|[`NullReferenceException`](https://learn.microsoft.com/dotnet/api/system.nullreferenceexception)|Thrown when an attempt is made to reference an object whose value is [null](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null).|
|[`OutOfMemoryException`](https://learn.microsoft.com/dotnet/api/system.outofmemoryexception)|Thrown when an attempt to allocate memory using the [new](https://learn.microsoft.com/dotnet/csharp/language-reference/operators/new-operator) operator fails. This exception indicates that the memory available to the common language runtime has been exhausted.|
|[`OverflowException`](https://learn.microsoft.com/dotnet/api/system.overflowexception)|Thrown when an arithmetic operation in a `checked` context overflows.|
|[`StackOverflowException`](https://learn.microsoft.com/dotnet/api/system.stackoverflowexception)|Thrown when the execution stack is exhausted by having too many pending method calls; usually indicates a very deep or infinite recursion.|
|[`TypeInitializationException`](https://learn.microsoft.com/dotnet/api/system.typeinitializationexception)|Thrown when a static constructor throws an exception and no compatible `catch` clause exists to catch it.|
