# dotnet test

**This article applies to:** ✔️ .NET 6 SDK and later versions

## Name <a class="anchor" href="#name" id="name">#</a>
`dotnet test` - .NET test driver used to execute unit tests.

## Description <a class="anchor" href="#description" id="description">#</a>
The `dotnet test` command builds the solution and runs the tests with either VSTest or Microsoft Testing Platform (MTP). The test runner you use determines the available command-line options and behavior.

> **\1**
>
> Test runner selection is available starting with .NET 10 SDK. In earlier versions of .NET, tests are always executed with VSTest.

### Choosing a test runner <a class="anchor" href="#choosing-a-test-runner" id="choosing-a-test-runner">#</a>
To enable Microsoft.Testing.Platform (MTP), you need to specify the test runner in the [`global.json`](https://learn.microsoft.com/dotnet/core/tools/global-json) file:

```json
{
    "test": {
        "runner": "Microsoft.Testing.Platform"
    }
}
```

> **\1**
>
> `VSTest` is a valid value for test runner. It is the current default and can be omitted.
>
> **\1**
>
> The `dotnet test` experience for MTP is only supported in `Microsoft.Testing.Platform` version 1.7 and later.

### Test runner documentation <a class="anchor" href="#test-runner-documentation" id="test-runner-documentation">#</a>
The available command-line options, behavior, and capabilities differ depending on which test runner you use:

- **[dotnet test with VSTest](https://learn.microsoft.com/dotnet/core/tools/dotnet-test-vstest)** - The traditional test platform, available in .NET 6 SDK and later. This is the default and only test runner in versions earlier than .NET 10 SDK. Provides comprehensive test discovery, filtering, and result reporting capabilities.

- **[dotnet test with MTP](https://learn.microsoft.com/dotnet/core/tools/dotnet-test-mtp)** - The modern testing platform, available in .NET 10 SDK and later. Offers faster test execution and more flexible test module selection.

> **\1**
>
> For conceptual documentation about `dotnet test`, see [Testing with dotnet test](https://learn.microsoft.com/dotnet/core/testing/unit-testing-with-dotnet-test).
