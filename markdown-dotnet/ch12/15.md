# Runtime libraries overview

The [.NET runtime](../ch0/1.html) has an expansive standard set of class libraries, known as [runtime libraries](https://learn.microsoft.com/dotnet/standard/glossary#runtime), [framework libraries](https://learn.microsoft.com/dotnet/standard/glossary#framework-libraries), or the [base class library (BCL)](https://learn.microsoft.com/dotnet/standard/glossary#bcl). In addition, there are extensions to the runtime libraries, which are provided in NuGet packages.

These libraries provide implementations for many general and app-specific types, algorithms, and utility functionality.

## Runtime libraries <a class="anchor" href="#runtime-libraries" id="runtime-libraries">#</a>
The runtime libraries provide the foundational types and utility functionality and are the base of all other .NET class libraries. An example is the [`System.String`](https://learn.microsoft.com/dotnet/api/system.string) class, which provides APIs for working with strings. Another example is the [serialization libraries](../ch12/16.html).

## Extensions to the runtime libraries <a class="anchor" href="#extensions-to-the-runtime-libraries" id="extensions-to-the-runtime-libraries">#</a>
Some libraries are provided in NuGet packages rather than as part of the runtime's [shared framework](https://learn.microsoft.com/dotnet/standard/glossary#shared-framework). These libraries are often made available to apps that target downlevel .NET versions, such as .NET Framework, as well.

The following table shows some examples of package-provided libraries.

|---------------------------------|----------------------------------------|
| [`Microsoft.Extensions.AI`][ai] | [AI](https://learn.microsoft.com/dotnet/ai/microsoft-extensions-ai) |
| [`Microsoft.Extensions.Configuration`][configuration] | [Configuration](https://learn.microsoft.com/dotnet/core/extensions/configuration) |
| [`Microsoft.Extensions.DependencyInjection`][di] | [Dependency injection](https://learn.microsoft.com/dotnet/core/extensions/dependency-injection/overview) |
| [`Microsoft.Extensions.FileSystemGlobbing`][fsg] | [File globbing](https://learn.microsoft.com/dotnet/core/extensions/file-globbing) |
| [`Microsoft.Extensions.Hosting`][host] | [Generic Host](https://learn.microsoft.com/dotnet/core/extensions/generic-host) |
| [`Microsoft.Extensions.Http`][http] | [HTTP](https://learn.microsoft.com/dotnet/core/extensions/httpclient-factory) |
| [`Microsoft.Extensions.Localization`][loc] | [Localization](https://learn.microsoft.com/dotnet/core/extensions/localization) |
| [`Microsoft.Extensions.Logging`][log] | [Logging](https://learn.microsoft.com/dotnet/core/extensions/logging/overview) |
