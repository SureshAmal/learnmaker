# Generic interfaces in .NET

This article provides an overview of .NET's generic interfaces that provide common functionality across families of generic types.

Generic interfaces provide type-safe counterparts to nongeneric interfaces for ordering and equality comparisons, and for functionality that's shared by generic collection types. .NET 7 introduces generic interfaces for number-like types, for example, [`System.Numerics.INumber`](https://learn.microsoft.com/dotnet/api/system.numerics.inumber). These interfaces let you define generic methods that provide mathematical functionality, where the generic type parameter is constrained to be a type that implements a generic, numeric interface.

> **\1**
>
> The type parameters of several generic interfaces are marked covariant or contravariant, providing greater flexibility in assigning and using types that implement these interfaces. For more information, see [Covariance and Contravariance](../ch7/22.html).

## Equality and ordering comparisons <a class="anchor" href="#equality-and-ordering-comparisons" id="equality-and-ordering-comparisons">#</a>
- In the [`System`](https://learn.microsoft.com/dotnet/api/system) namespace, the **[`System.IComparable`](https://learn.microsoft.com/dotnet/api/system.icomparable)** and **[`System.IEquatable`](https://learn.microsoft.com/dotnet/api/system.iequatable)** generic interfaces, like their nongeneric counterparts, define methods for ordering comparisons and equality comparisons, respectively. Types implement these interfaces to provide the ability to perform such comparisons.

- In the [`Generic`](https://learn.microsoft.com/dotnet/api/system.collections.generic) namespace, the **[`IComparer`](https://learn.microsoft.com/dotnet/api/system.collections.generic.icomparer)** and **[`IEqualityComparer`](https://learn.microsoft.com/dotnet/api/system.collections.generic.iequalitycomparer)** generic interfaces offer a way to define an ordering or equality comparison for types that don't implement the [`System.IComparable`](https://learn.microsoft.com/dotnet/api/system.icomparable) or [`System.IEquatable`](https://learn.microsoft.com/dotnet/api/system.iequatable) interface. They also provide a way to redefine those relationships for types that do.

  These interfaces are used by methods and constructors of many of the generic collection classes. For example, you can pass a generic [`IComparer`](https://learn.microsoft.com/dotnet/api/system.collections.generic.icomparer) object to the constructor of the [`SortedDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.generic.sorteddictionary) class to specify a sort order for a type that does not implement generic [`System.IComparable`](https://learn.microsoft.com/dotnet/api/system.icomparable). There are overloads of the [`System.Array.Sort`](https://learn.microsoft.com/dotnet/api/system.array.sort) generic static method and the [`System.Collections.Generic.List`1.Sort`](https://learn.microsoft.com/dotnet/api/system.collections.generic.list-1.sort) instance method for sorting arrays and lists using generic [`IComparer`](https://learn.microsoft.com/dotnet/api/system.collections.generic.icomparer) implementations.

  The [`Comparer`](https://learn.microsoft.com/dotnet/api/system.collections.generic.comparer) and [`EqualityComparer`](https://learn.microsoft.com/dotnet/api/system.collections.generic.equalitycomparer) generic classes provide base classes for implementations of the [`IComparer`](https://learn.microsoft.com/dotnet/api/system.collections.generic.icomparer) and [`IEqualityComparer`](https://learn.microsoft.com/dotnet/api/system.collections.generic.iequalitycomparer) generic interfaces and also provide default ordering and equality comparisons through their respective [`System.Collections.Generic.Comparer`1.Default`](https://learn.microsoft.com/dotnet/api/system.collections.generic.comparer-1.default) and [`System.Collections.Generic.EqualityComparer`1.Default`](https://learn.microsoft.com/dotnet/api/system.collections.generic.equalitycomparer-1.default) properties.

## Collection functionality <a class="anchor" href="#collection-functionality" id="collection-functionality">#</a>
- The **[`ICollection`](https://learn.microsoft.com/dotnet/api/system.collections.generic.icollection)** generic interface is the basic interface for generic collection types. It provides basic functionality for adding, removing, copying, and enumerating elements. [`ICollection`](https://learn.microsoft.com/dotnet/api/system.collections.generic.icollection) inherits from both generic [`IEnumerable`](https://learn.microsoft.com/dotnet/api/system.collections.generic.ienumerable) and nongeneric [`IEnumerable`](https://learn.microsoft.com/dotnet/api/system.collections.ienumerable).

- The **[`IList`](https://learn.microsoft.com/dotnet/api/system.collections.generic.ilist)** generic interface extends the [`ICollection`](https://learn.microsoft.com/dotnet/api/system.collections.generic.icollection) generic interface with methods for indexed retrieval.

- The **[`IDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.generic.idictionary)** generic interface extends the [`ICollection`](https://learn.microsoft.com/dotnet/api/system.collections.generic.icollection) generic interface with methods for keyed retrieval. Generic dictionary types in the .NET base class library also implement the nongeneric [`IDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.idictionary) interface.

- The **[`IEnumerable`](https://learn.microsoft.com/dotnet/api/system.collections.generic.ienumerable)** generic interface provides a generic enumerator structure. The [`IEnumerator`](https://learn.microsoft.com/dotnet/api/system.collections.generic.ienumerator) generic interface implemented by generic enumerators inherits the nongeneric [`IEnumerator`](https://learn.microsoft.com/dotnet/api/system.collections.ienumerator) interface; the [`MoveNext`](https://learn.microsoft.com/dotnet/api/system.collections.ienumerator.movenext) and [`Reset`](https://learn.microsoft.com/dotnet/api/system.collections.ienumerator.reset) members, which do not depend on the type parameter `T`, appear only on the nongeneric interface. This means that any consumer of the nongeneric interface can also consume the generic interface.

## Mathematical functionality <a class="anchor" href="#mathematical-functionality" id="mathematical-functionality">#</a>
.NET 7 introduces generic interfaces in the [`System.Numerics`](https://learn.microsoft.com/dotnet/api/system.numerics) namespace that describe number-like types and the functionality available to them. The 20 numeric types that the .NET base class library provides, for example, [`Int32`](https://learn.microsoft.com/dotnet/api/system.int32) and [`Double`](https://learn.microsoft.com/dotnet/api/system.double), have been updated to implement these interfaces. The most prominent of these interfaces is [`INumber`](https://learn.microsoft.com/dotnet/api/system.numerics.inumber), which roughly corresponds to a "real" number.

For more information about these interfaces, see [Generic math](https://learn.microsoft.com/dotnet/standard/generics/math).
