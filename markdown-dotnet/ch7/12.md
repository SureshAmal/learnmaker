# Selecting a Collection Class

Be sure to choose your collection class carefully. Using the wrong type can restrict your use of the collection.

> **\1**
>
> Avoid using the types in the [`Collections`](https://learn.microsoft.com/dotnet/api/system.collections) namespace. The generic and concurrent versions of the collections are recommended because of their greater type safety and other improvements.

Consider the following questions:

- Do you need a sequential list where the element is typically discarded after its value is retrieved?

  - If yes, consider using the [`Queue`](https://learn.microsoft.com/dotnet/api/system.collections.queue) class or the [`Queue`](https://learn.microsoft.com/dotnet/api/system.collections.generic.queue) generic class if you need first-in, first-out (FIFO) behavior. Consider using the [`Stack`](https://learn.microsoft.com/dotnet/api/system.collections.stack) class or the [`Stack`](https://learn.microsoft.com/dotnet/api/system.collections.generic.stack) generic class if you need last-in, first-out (LIFO) behavior. For safe access from multiple threads, use the concurrent versions, [`ConcurrentQueue`](https://learn.microsoft.com/dotnet/api/system.collections.concurrent.concurrentqueue) and [`ConcurrentStack`](https://learn.microsoft.com/dotnet/api/system.collections.concurrent.concurrentstack). For immutability, consider the immutable versions, [`ImmutableQueue`](https://learn.microsoft.com/dotnet/api/system.collections.immutable.immutablequeue) and [`ImmutableStack`](https://learn.microsoft.com/dotnet/api/system.collections.immutable.immutablestack).

  - If not, consider using the other collections.

- Do you need to access the elements in a certain order, such as FIFO, LIFO, or random?

  - The [`Queue`](https://learn.microsoft.com/dotnet/api/system.collections.queue) class, as well as the [`Queue`](https://learn.microsoft.com/dotnet/api/system.collections.generic.queue), [`ConcurrentQueue`](https://learn.microsoft.com/dotnet/api/system.collections.concurrent.concurrentqueue), and [`ImmutableQueue`](https://learn.microsoft.com/dotnet/api/system.collections.immutable.immutablequeue) generic classes all offer FIFO access. For more information, see [When to Use a Thread-Safe Collection](../ch7/17.html).

  - The [`Stack`](https://learn.microsoft.com/dotnet/api/system.collections.stack) class, as well as the [`Stack`](https://learn.microsoft.com/dotnet/api/system.collections.generic.stack), [`ConcurrentStack`](https://learn.microsoft.com/dotnet/api/system.collections.concurrent.concurrentstack), and [`ImmutableStack`](https://learn.microsoft.com/dotnet/api/system.collections.immutable.immutablestack) generic classes all offer LIFO access. For more information, see [When to Use a Thread-Safe Collection](../ch7/17.html).

  - The [`LinkedList`](https://learn.microsoft.com/dotnet/api/system.collections.generic.linkedlist) generic class allows sequential access either from the head to the tail, or from the tail to the head.

- Do you need to access each element by index?

  - The [`ArrayList`](https://learn.microsoft.com/dotnet/api/system.collections.arraylist) and [`StringCollection`](https://learn.microsoft.com/dotnet/api/system.collections.specialized.stringcollection) classes and the [`List`](https://learn.microsoft.com/dotnet/api/system.collections.generic.list) generic class offer access to their elements by the zero-based index of the element. For immutability, consider the immutable generic versions, [`ImmutableArray`](https://learn.microsoft.com/dotnet/api/system.collections.immutable.immutablearray) and [`ImmutableList`](https://learn.microsoft.com/dotnet/api/system.collections.immutable.immutablelist).

  - The [`Hashtable`](https://learn.microsoft.com/dotnet/api/system.collections.hashtable), [`SortedList`](https://learn.microsoft.com/dotnet/api/system.collections.sortedlist), [`ListDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.specialized.listdictionary), and [`StringDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.specialized.stringdictionary) classes, and the [`Dictionary`](https://learn.microsoft.com/dotnet/api/system.collections.generic.dictionary) and [`SortedDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.generic.sorteddictionary) generic classes offer access to their elements by the key of the element. Additionally, there are immutable versions of several corresponding types: [`ImmutableHashSet`](https://learn.microsoft.com/dotnet/api/system.collections.immutable.immutablehashset), [`ImmutableDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.immutable.immutabledictionary), [`ImmutableSortedSet`](https://learn.microsoft.com/dotnet/api/system.collections.immutable.immutablesortedset), and [`ImmutableSortedDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.immutable.immutablesorteddictionary).

  - The [`NameObjectCollectionBase`](https://learn.microsoft.com/dotnet/api/system.collections.specialized.nameobjectcollectionbase) and [`NameValueCollection`](https://learn.microsoft.com/dotnet/api/system.collections.specialized.namevaluecollection) classes, and the [`KeyedCollection`](https://learn.microsoft.com/dotnet/api/system.collections.objectmodel.keyedcollection) and [`SortedList`](https://learn.microsoft.com/dotnet/api/system.collections.generic.sortedlist) generic classes offer access to their elements by either the zero-based index or the key of the element.

- Will each element contain one value, a combination of one key and one value, or a combination of one key and multiple values?

  - One value: Use any of the collections based on the [`IList`](https://learn.microsoft.com/dotnet/api/system.collections.ilist) interface or the [`IList`](https://learn.microsoft.com/dotnet/api/system.collections.generic.ilist) generic interface. For an immutable option, consider the [`IImmutableList`](https://learn.microsoft.com/dotnet/api/system.collections.immutable.iimmutablelist) generic interface.

  - One key and one value: Use any of the collections based on the [`IDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.idictionary) interface or the [`IDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.generic.idictionary) generic interface. For an immutable option, consider the [`IImmutableSet`](https://learn.microsoft.com/dotnet/api/system.collections.immutable.iimmutableset) or [`IImmutableDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.immutable.iimmutabledictionary) generic interfaces.

  - One value with embedded key: Use the [`KeyedCollection`](https://learn.microsoft.com/dotnet/api/system.collections.objectmodel.keyedcollection) generic class.

  - One key and multiple values: Use the [`NameValueCollection`](https://learn.microsoft.com/dotnet/api/system.collections.specialized.namevaluecollection) class.

- Do you need to sort the elements differently from how they were entered?

  - The [`Hashtable`](https://learn.microsoft.com/dotnet/api/system.collections.hashtable) class sorts its elements by their hash codes.

  - The [`SortedList`](https://learn.microsoft.com/dotnet/api/system.collections.sortedlist) class, and the [`SortedList`](https://learn.microsoft.com/dotnet/api/system.collections.generic.sortedlist) and [`SortedDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.generic.sorteddictionary) generic classes sort their elements by the key. The sort order is based on the implementation of the [`IComparer`](https://learn.microsoft.com/dotnet/api/system.collections.icomparer) interface for the [`SortedList`](https://learn.microsoft.com/dotnet/api/system.collections.sortedlist) class and on the implementation of the [`IComparer`](https://learn.microsoft.com/dotnet/api/system.collections.generic.icomparer) generic interface for the [`SortedList`](https://learn.microsoft.com/dotnet/api/system.collections.generic.sortedlist) and [`SortedDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.generic.sorteddictionary) generic classes. Of the two generic types, [`SortedDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.generic.sorteddictionary) offers better performance than [`SortedList`](https://learn.microsoft.com/dotnet/api/system.collections.generic.sortedlist), while [`SortedList`](https://learn.microsoft.com/dotnet/api/system.collections.generic.sortedlist) consumes less memory.

  - [`ArrayList`](https://learn.microsoft.com/dotnet/api/system.collections.arraylist) provides a [`Sort`](https://learn.microsoft.com/dotnet/api/system.collections.arraylist.sort) method that takes an [`IComparer`](https://learn.microsoft.com/dotnet/api/system.collections.icomparer) implementation as a parameter. Its generic counterpart, the [`List`](https://learn.microsoft.com/dotnet/api/system.collections.generic.list) generic class, provides a [`Sort`](https://learn.microsoft.com/dotnet/api/system.collections.generic.list-1.sort) method that takes an implementation of the [`IComparer`](https://learn.microsoft.com/dotnet/api/system.collections.generic.icomparer) generic interface as a parameter.

- Do you need fast searches and retrieval of information?

  - [`ListDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.specialized.listdictionary) is faster than [`Hashtable`](https://learn.microsoft.com/dotnet/api/system.collections.hashtable) for small collections (10 items or fewer). The [`Dictionary`](https://learn.microsoft.com/dotnet/api/system.collections.generic.dictionary) generic class provides faster lookup than the [`SortedDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.generic.sorteddictionary) generic class. The multi-threaded implementation is [`ConcurrentDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.concurrent.concurrentdictionary). [`ConcurrentBag`](https://learn.microsoft.com/dotnet/api/system.collections.concurrent.concurrentbag) provides fast multi-threaded insertion for unordered data. For more information about both multi-threaded types, see [When to Use a Thread-Safe Collection](../ch7/17.html).

- Do you need collections that accept only strings?

  - [`StringCollection`](https://learn.microsoft.com/dotnet/api/system.collections.specialized.stringcollection) (based on [`IList`](https://learn.microsoft.com/dotnet/api/system.collections.ilist)) and [`StringDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.specialized.stringdictionary) (based on [`IDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.idictionary)) are in the [`Specialized`](https://learn.microsoft.com/dotnet/api/system.collections.specialized) namespace.

  - In addition, you can use any of the generic collection classes in the [`Generic`](https://learn.microsoft.com/dotnet/api/system.collections.generic) namespace as strongly typed string collections by specifying the [`String`](https://learn.microsoft.com/dotnet/api/system.string) class for their generic type arguments. For example, you can declare a variable to be of type [List\<String>](https://learn.microsoft.com/dotnet/api/system.collections.generic.list) or [Dictionary<String,String>](https://learn.microsoft.com/dotnet/api/system.collections.generic.dictionary).

## LINQ to Objects and PLINQ <a class="anchor" href="#linq-to-objects-and-plinq" id="linq-to-objects-and-plinq">#</a>
LINQ to Objects enables developers to use LINQ queries to access in-memory objects as long as the object type implements [`IEnumerable`](https://learn.microsoft.com/dotnet/api/system.collections.ienumerable) or [`IEnumerable`](https://learn.microsoft.com/dotnet/api/system.collections.generic.ienumerable). LINQ queries provide a common pattern for accessing data, are typically more concise and readable than standard `foreach` loops, and provide filtering, ordering, and grouping capabilities. For more information, see [LINQ to Objects (C#)](../ch8/2.html) and [LINQ to Objects (Visual Basic)](https://learn.microsoft.com/dotnet/visual-basic/programming-guide/concepts/linq/linq-to-objects).

PLINQ provides a parallel implementation of LINQ to Objects that can offer faster query execution in many scenarios, through more efficient use of multi-core computers. For more information, see [Parallel LINQ (PLINQ)](https://learn.microsoft.com/dotnet/standard/parallel-programming/introduction-to-plinq).
