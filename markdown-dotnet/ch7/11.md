# Commonly used collection types

Collection types represent different ways to collect data, such as hash tables, queues, stacks, bags, dictionaries, and lists.

All collections are based on the [`ICollection`](https://learn.microsoft.com/dotnet/api/system.collections.icollection) or [`ICollection`](https://learn.microsoft.com/dotnet/api/system.collections.generic.icollection) interfaces, either directly or indirectly. [`IList`](https://learn.microsoft.com/dotnet/api/system.collections.ilist) and [`IDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.idictionary) and their generic counterparts all derive from these two interfaces.

In collections based on [`IList`](https://learn.microsoft.com/dotnet/api/system.collections.ilist) or directly on [`ICollection`](https://learn.microsoft.com/dotnet/api/system.collections.icollection), every element contains only a value. These types include:

- [`Array`](https://learn.microsoft.com/dotnet/api/system.array)
- [`ArrayList`](https://learn.microsoft.com/dotnet/api/system.collections.arraylist)
- [`List`](https://learn.microsoft.com/dotnet/api/system.collections.generic.list)
- [`Queue`](https://learn.microsoft.com/dotnet/api/system.collections.queue)
- [`ConcurrentQueue`](https://learn.microsoft.com/dotnet/api/system.collections.concurrent.concurrentqueue)
- [`Stack`](https://learn.microsoft.com/dotnet/api/system.collections.stack)
- [`ConcurrentStack`](https://learn.microsoft.com/dotnet/api/system.collections.concurrent.concurrentstack)
- [`LinkedList`](https://learn.microsoft.com/dotnet/api/system.collections.generic.linkedlist)

In collections based on the [`IDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.idictionary) interface, every element contains both a key and a value. These types include:

- [`Hashtable`](https://learn.microsoft.com/dotnet/api/system.collections.hashtable)
- [`SortedList`](https://learn.microsoft.com/dotnet/api/system.collections.sortedlist)
- [`SortedList`](https://learn.microsoft.com/dotnet/api/system.collections.generic.sortedlist)
- [`Dictionary`](https://learn.microsoft.com/dotnet/api/system.collections.generic.dictionary)
- [`ConcurrentDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.concurrent.concurrentdictionary)

The [`KeyedCollection`](https://learn.microsoft.com/dotnet/api/system.collections.objectmodel.keyedcollection) class is unique because it is a list of values with keys embedded within the values. As a result, it behaves both like a list and like a dictionary.

When you need efficient multi-threaded collection access, use the generic collections in the [`Concurrent`](https://learn.microsoft.com/dotnet/api/system.collections.concurrent) namespace.

The [`Queue`](https://learn.microsoft.com/dotnet/api/system.collections.queue) and [`Queue`](https://learn.microsoft.com/dotnet/api/system.collections.generic.queue) classes provide first-in-first-out lists. The [`Stack`](https://learn.microsoft.com/dotnet/api/system.collections.stack) and [`Stack`](https://learn.microsoft.com/dotnet/api/system.collections.generic.stack) classes provide last-in-first-out lists.

## Strong typing <a class="anchor" href="#strong-typing" id="strong-typing">#</a>
Generic collections are the best solution to strong typing. For example, adding an element of any type other than an [`Int32`](https://learn.microsoft.com/dotnet/api/system.int32) to a `List<Int32>` collection causes a compile-time error. However, if your language does not support generics, the [`Collections`](https://learn.microsoft.com/dotnet/api/system.collections) namespace includes abstract base classes that you can extend to create collection classes that are strongly typed. These base classes include:

- [`CollectionBase`](https://learn.microsoft.com/dotnet/api/system.collections.collectionbase)
- [`ReadOnlyCollectionBase`](https://learn.microsoft.com/dotnet/api/system.collections.readonlycollectionbase)
- [`DictionaryBase`](https://learn.microsoft.com/dotnet/api/system.collections.dictionarybase)

## How collections vary <a class="anchor" href="#how-collections-vary" id="how-collections-vary">#</a>
Collections vary in how they store, sort, and compare elements, and how they perform searches.

The [`SortedList`](https://learn.microsoft.com/dotnet/api/system.collections.sortedlist) class and the [`SortedList`](https://learn.microsoft.com/dotnet/api/system.collections.generic.sortedlist) generic class provide sorted versions of the [`Hashtable`](https://learn.microsoft.com/dotnet/api/system.collections.hashtable) class and the [`Dictionary`](https://learn.microsoft.com/dotnet/api/system.collections.generic.dictionary) generic class.

All collections use zero-based indexes except [`Array`](https://learn.microsoft.com/dotnet/api/system.array), which allows arrays that are not zero-based.

You can access the elements of a [`SortedList`](https://learn.microsoft.com/dotnet/api/system.collections.sortedlist) or a [`KeyedCollection`](https://learn.microsoft.com/dotnet/api/system.collections.objectmodel.keyedcollection) by either the key or the element's index. You can only access the elements of a [`Hashtable`](https://learn.microsoft.com/dotnet/api/system.collections.hashtable) or a [`Dictionary`](https://learn.microsoft.com/dotnet/api/system.collections.generic.dictionary) by the element's key.

## Use LINQ with collection types <a class="anchor" href="#use-linq-with-collection-types" id="use-linq-with-collection-types">#</a>
The LINQ to Objects feature provides a common pattern for accessing in-memory objects of any type that implements [`IEnumerable`](https://learn.microsoft.com/dotnet/api/system.collections.ienumerable) or [`IEnumerable`](https://learn.microsoft.com/dotnet/api/system.collections.generic.ienumerable). LINQ queries have several benefits over standard constructs like `foreach` loops:

- They are concise and easier to understand.
- They can filter, order, and group data.
- They can improve performance.

For more information, see [LINQ to Objects (C#)](../ch8/2.html), [LINQ to Objects (Visual Basic)](https://learn.microsoft.com/dotnet/visual-basic/programming-guide/concepts/linq/linq-to-objects), and [Parallel LINQ (PLINQ)](https://learn.microsoft.com/dotnet/standard/parallel-programming/introduction-to-plinq).
