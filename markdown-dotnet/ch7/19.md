# Generic collections in .NET

The .NET class library provides a number of generic collection classes in the [`Generic`](https://learn.microsoft.com/dotnet/api/system.collections.generic) and [`ObjectModel`](https://learn.microsoft.com/dotnet/api/system.collections.objectmodel) namespaces. For more detailed information about these classes, see [Commonly Used Collection Types](../ch7/11.html).

## System.Collections.Generic <a class="anchor" href="#systemcollectionsgeneric" id="systemcollectionsgeneric">#</a>
 Many of the generic collection types are direct analogs of nongeneric types. [`Dictionary`](https://learn.microsoft.com/dotnet/api/system.collections.generic.dictionary) is a generic version of [`Hashtable`](https://learn.microsoft.com/dotnet/api/system.collections.hashtable); it uses the generic structure [`KeyValuePair`](https://learn.microsoft.com/dotnet/api/system.collections.generic.keyvaluepair) for enumeration instead of [`DictionaryEntry`](https://learn.microsoft.com/dotnet/api/system.collections.dictionaryentry).

 [`List`](https://learn.microsoft.com/dotnet/api/system.collections.generic.list) is a generic version of [`ArrayList`](https://learn.microsoft.com/dotnet/api/system.collections.arraylist). There are generic [`Queue`](https://learn.microsoft.com/dotnet/api/system.collections.generic.queue) and [`Stack`](https://learn.microsoft.com/dotnet/api/system.collections.generic.stack) classes that correspond to the nongeneric versions.

 There are generic and nongeneric versions of [`SortedList`](https://learn.microsoft.com/dotnet/api/system.collections.generic.sortedlist). Both versions are hybrids of a dictionary and a list. The [`SortedDictionary`](https://learn.microsoft.com/dotnet/api/system.collections.generic.sorteddictionary) generic class is a pure dictionary and has no nongeneric counterpart.

 The [`LinkedList`](https://learn.microsoft.com/dotnet/api/system.collections.generic.linkedlist) generic class is a true linked list. It has no nongeneric counterpart.

## System.Collections.ObjectModel <a class="anchor" href="#systemcollectionsobjectmodel" id="systemcollectionsobjectmodel">#</a>
 The [`Collection`](https://learn.microsoft.com/dotnet/api/system.collections.objectmodel.collection) generic class provides a base class for deriving your own generic collection types. The [`ReadOnlyCollection`](https://learn.microsoft.com/dotnet/api/system.collections.objectmodel.readonlycollection) class provides an easy way to produce a read-only collection from any type that implements the [`IList`](https://learn.microsoft.com/dotnet/api/system.collections.generic.ilist) generic interface. The [`KeyedCollection`](https://learn.microsoft.com/dotnet/api/system.collections.objectmodel.keyedcollection) generic class provides a way to store objects that contain their own keys.

## Other generic types <a class="anchor" href="#other-generic-types" id="other-generic-types">#</a>
 The [`Nullable`](https://learn.microsoft.com/dotnet/api/system.nullable) generic structure allows you to use value types as if they could be assigned `null`. This can be useful when working with database queries, where fields that contain value types can be missing. The generic type parameter can be any value type.

> **\1**
>
> In C# and Visual Basic, it is not necessary to use [`Nullable`](https://learn.microsoft.com/dotnet/api/system.nullable) explicitly because the language has syntax for nullable types. See [Nullable value types (C# reference)](https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/nullable-value-types) and [Nullable value types (Visual Basic)](https://learn.microsoft.com/dotnet/visual-basic/programming-guide/language-features/data-types/nullable-value-types).

 The [`ArraySegment`](https://learn.microsoft.com/dotnet/api/system.arraysegment) generic structure provides a way to delimit a range of elements within a one-dimensional, zero-based array of any type. The generic type parameter is the type of the array's elements.

 The [`EventHandler`](https://learn.microsoft.com/dotnet/api/system.eventhandler) generic delegate eliminates the need to declare a delegate type to handle events, if your event follows the event-handling pattern used by .NET. For example, suppose you have created a `MyEventArgs` class, derived from [`EventArgs`](https://learn.microsoft.com/dotnet/api/system.eventargs), to hold the data for your event. You can then declare the event as follows:

```csharp
public event EventHandler<MyEventArgs> MyEvent;
```


```vb
Public Event MyEvent As EventHandler(Of MyEventArgs)
```
