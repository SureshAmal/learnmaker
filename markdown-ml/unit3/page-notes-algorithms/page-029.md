## Concept Explanation
**Stacking (Stacked Generalization)** is an ensemble learning strategy that differs from Bagging (like Random Forest) or Boosting (like AdaBoost) by using a two-layer architecture:

1.  **Layer 0 (Base Models):** You train several different types of machine learning models (e.g., a Decision Tree, a Support Vector Machine, and a K-Nearest Neighbor) on the same dataset. Because these models have different biases and mathematical foundations, they will likely make different types of errors.
2.  **Layer 1 (Meta-Model):** Instead of using a simple majority vote or an average of the base models' predictions, Stacking uses another machine learning model (the meta-model). The inputs for this meta-model are the *outputs* (predictions) of the base models. 
3.  **Goal:** The meta-model "learns" which base model is more reliable for certain types of data points. For example, it might learn that when the SVM and Decision Tree disagree, the SVM is usually correct. This allows the ensemble to leverage the unique strengths of diverse learners to achieve higher accuracy than any single model could achieve alone.

## Exam / Viva Points
*   **Definition:** Stacking is an ensemble method where a meta-model is trained to combine the predictions of several base learners.
*   **Meta-model Input:** The features for the meta-model are the predictions generated by the base models.
*   **Diversity:** Stacking is most effective when the base models are "diverse," meaning they are different types of algorithms that make uncorrelated errors.
*   **Common Meta-models:** Logistic Regression is a frequent choice for the meta-model in classification tasks because it is simple and provides a smooth combination of inputs.
*   **Difference from Voting:** Unlike simple voting (which treats all models equally), the meta-model in stacking is trained to weight the models optimally based on their performance.
