## Diagram Type

## Diagram / Visual Explanation
1.  **Step 1:** The original **Training Set** (yellow) is used to train multiple base **Models** (red). In practice, these are often diverse algorithms like a Decision Tree, a Support Vector Machine, and a k-Nearest Neighbors model.
2.  **Step 2:** Once trained, these base models make predictions on the training data (or a hold-out set). These predictions are collected to form a **New Training Set** (green). In this new set, the "features" are the outputs of the base models.
3.  **Step 3:** This new dataset is used for **training** the **Meta Model** (teal). The meta-model learns how to best weigh or combine the predictions from the base models to minimize error.
4.  **Step 4:** The trained meta-model generates the **Final Predictions** (purple).

## Concept Explanation
**Stacking** is an ensemble learning technique that combines multiple classification or regression models via a meta-classifier or a meta-regressor. 

*   **Level-0 Models (Base Models):** These are the first layer of models. They are trained on the complete original dataset. The goal is to have a diverse set of models that make different types of errors.
*   **Level-1 Model (Meta-Model):** This model sits on top of the base models. Its input is not the original raw data, but rather the predictions made by the Level-0 models. It acts as a "judge" that learns which base model to trust more in different scenarios.
*   **The "New Training Set":** To prevent overfitting, the new training set is often created using a technique like k-fold cross-validation. The meta-model is trained on the "out-of-fold" predictions of the base models.

## Exam / Viva Points
*   **Definition:** Stacking is an ensemble method where a meta-model learns how to best combine the predictions from multiple base models.
*   **Key Difference:** Unlike Bagging (which uses parallel identical models) or Boosting (which uses sequential models to fix errors), Stacking uses a separate model to learn the combination logic.
*   **Input to Meta-Model:** The features for the meta-model are the predictions (class labels or probabilities) generated by the base models.
*   **Diversity:** For stacking to be effective, the base models should be diverse (e.g., using different algorithms) so they capture different patterns in the data.
*   **Overfitting Risk:** Mention that using the same data to train base models and the meta-model can lead to overfitting; hence, cross-validation is typically used to generate the "New Training Set."
