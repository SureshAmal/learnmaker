## Concept Explanation
*   **Discriminant Function:** In machine learning, this is a function $g(x)$ that maps an input vector $x$ to a specific class. In a multi-class scenario, the system often calculates multiple discriminant functions (one for each class) and chooses the class that yields the highest value.
*   **Classification:** This is the task of predicting a discrete label (class) for a given input. For example, determining if an email is "spam" or "not spam."
*   **Feature Vector:** This is a numerical representation of an object's characteristics. For instance, if classifying fruit, the feature vector might contain values for weight, color (as a number), and diameter.
*   **Mechanism of Comparison:** The discriminant function acts as a decision-maker. By calculating values for different classes based on the input features, it creates "decision boundaries" in the feature space. The class assignment is made by comparing these calculated values to see which class the data point most likely belongs to.

## Exam / Viva Points
*   **Definition:** A discriminant function is a mathematical tool used to partition a feature space into different regions, each representing a class.
*   **Input/Output:** It takes a **feature vector** as input and outputs a **class assignment**.
*   **Decision Rule:** The assignment is typically made by comparing the values of different discriminant functions and selecting the one with the maximum value (the "winner-take-all" approach).
*   **Context:** It is a core component of supervised learning algorithms used for classification and pattern recognition.
