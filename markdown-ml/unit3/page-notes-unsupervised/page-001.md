## Concept Explanation
**Unsupervised Learning** is a fundamental category of machine learning where the algorithm is trained on data that has not been labeled, classified, or categorized. 
*   **Goal:** The objective is for the model to act on the information without prior training or guidance. It attempts to find hidden structures, patterns, or features within the input data.
*   **Key Characteristics:** There is no "teacher" or "ground truth" (labels) to tell the model if its output is correct.
*   **Common Tasks:**
    *   **Clustering:** Grouping data points into clusters based on similarities (e.g., K-Means, Hierarchical Clustering).
    *   **Association:** Discovering rules that describe large portions of data (e.g., "people who buy X also buy Y").
    *   **Dimensionality Reduction:** Reducing the number of random variables under consideration (e.g., PCA).

## Exam / Viva Points
*   **Definition:** Unsupervised learning involves training models on unlabeled datasets to discover inherent patterns.
*   **Comparison:** Unlike Supervised Learning, which maps inputs to known outputs, Unsupervised Learning explores the data to find structure.
