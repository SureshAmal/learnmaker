## Concept Explanation
In the context of classification, a **Discriminant Function** is a mathematical function that takes an input vector (features) and assigns it to one of several classes. It essentially defines the "decision boundary" that separates different groups of data.

1.  **Linear Discriminant Function (LDF):** This approach assumes that the decision boundaries between classes are linear (i.e., straight lines in 2D, planes in 3D, or hyperplanes in higher dimensions). This typically occurs when different classes are assumed to have the same covariance matrix but different mean vectors.
2.  **Quadratic Discriminant Function (QDF):** This is a more flexible approach where the decision boundaries are quadratic (curves like ellipses, parabolas, or hyperbolas). This is used when each class is assumed to have its own unique covariance matrix, allowing for more complex separation of data points.
3.  **Bayesian Discriminant Function (BDF):** This is based on **Bayes' Theorem**. It calculates the posterior probability of a sample belonging to a specific class given its features. The classifier then assigns the sample to the class with the highest posterior probability, aiming to minimize the overall probability of classification error or the "Bayes risk."

## Exam / Viva Points
*   **Definition:** Be able to define a discriminant function as a tool for partitioning feature space into regions belonging to different classes.
*   **The Three Types:** Memorize the three types: Linear (LDF), Quadratic (QDF), and Bayesian (BDF).
*   **LDF vs. QDF:** A common question is the difference between them. Remember that LDF assumes equal covariance matrices across classes (resulting in straight boundaries), while QDF allows for different covariance matrices (resulting in curved boundaries).
*   **Optimality:** Understand that the Bayesian Discriminant Function is considered the "optimal" classifier if the underlying probability distributions of the classes are perfectly known, as it minimizes the total error rate.
*   **Acronyms:** Be familiar with the acronyms LDF, QDF, and BDF.
