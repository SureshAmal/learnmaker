## Concept Explanation
*   **Hierarchical Clustering:** This is an unsupervised machine learning algorithm that groups similar objects into groups called clusters. It creates a tree-like structure called a dendrogram.
*   **Dendrogram:** A visual representation of the steps in a hierarchical clustering solution. The y-axis usually represents the distance or similarity between clusters, and the x-axis represents the individual observations.
*   **Similarity Level / Cut-off:** To obtain a specific number of clusters from a dendrogram, you "cut" the tree horizontally at a certain height. The height corresponds to the similarity (or distance) between the clusters being merged. In this example, cutting at a similarity level of 40 yields 4 branches (clusters).
*   **Observations:** These are the individual data points or rows from the source dataset (worksheet). The slide explicitly maps these rows to the resulting clusters, showing how the algorithm has partitioned the data.

## Exam / Viva Points
*   **Determining Cluster Count:** A student should know that the number of clusters in a dendrogram is determined by where you draw a horizontal line (the cut-off). The number of vertical lines intersected by this horizontal line equals the number of clusters.
*   **Similarity vs. Distance:** Understand that dendrograms can be scaled by similarity (where higher values mean more alike) or distance (where lower values mean more alike). In this slide, a similarity level is used.
*   **Interpreting Membership:** Be prepared to explain how to identify which data points belong to which cluster by tracing the branches from the cut-off point down to the leaves (individual observations) at the bottom of the dendrogram.
*   **Cluster Ordering:** Note that the "far left" or "directly to the right" descriptions refer to the horizontal arrangement of clusters on the dendrogram's x-axis.
