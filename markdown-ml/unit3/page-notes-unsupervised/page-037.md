## Concept Explanation
The slide explains the application of **Association Rule Mining**, specifically using the **Apriori Algorithm**. The core concept is identifying "frequent itemsets"—groups of items that appear together frequently in a dataset.

1.  **E-commerce (Market Basket Analysis):** By analyzing transaction history, the algorithm finds that people who buy a laptop often also buy a bag. The system then automatically recommends the bag to anyone purchasing a laptop, a technique known as cross-selling.
2.  **Food Delivery (Product Bundling):** By seeing that burgers and fries are frequently ordered in the same transaction, services can create "Combo Deals." This simplifies the ordering process for the user and often increases the average order value.
3.  **Streaming Services (Content Recommendation):** Instead of physical products, the algorithm analyzes viewing sessions. If many users watch an action movie followed by a superhero movie, the service will recommend superhero movies to fans of action films, increasing user engagement and "watch time."

## Exam / Viva Points
*   **Primary Function:** The Apriori algorithm is used for finding frequent itemsets and association rules in large datasets.
*   **Market Basket Analysis:** This is the most common term for the E-commerce application mentioned (e.g., Laptop + Bag).
*   **Business Value:** The main goal of applying Apriori in these industries is to increase sales (via cross-selling), improve customer satisfaction (via relevant recommendations), and optimize product offerings (via combos).
*   **Data Input:** For these applications to work, the algorithm requires a large database of transactions or user activity logs.
