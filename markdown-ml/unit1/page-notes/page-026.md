## Concept Explanation
*   **Supervised Learning:** This is like learning with a teacher. The dataset contains "labels" or "ground truth" (the correct answers). The model learns the mapping from inputs to these known outputs so it can predict outputs for new, unseen data.
*   **Unsupervised Learning:** Here, the model works with data that has no labels. It acts like an explorer, looking for inherent structures, clusters, or hidden patterns within the data without being told what to look for.
*   **Semi-Supervised Learning:** This is a middle ground. It uses a small amount of labeled data to guide the learning process on a much larger pool of unlabeled data. This is highly practical because labeling data is often expensive and time-consuming.
*   **Reinforcement Learning:** This paradigm is based on interaction with an environment. An "agent" performs actions and receives feedback in the form of rewards (for good actions) or penalties (for bad ones). The goal is to learn a sequence of actions (a policy) that maximizes the total reward over time.

## Exam / Viva Points
*   **Supervised vs. Unsupervised:** The key difference is the presence of labels. Supervised uses labeled data for prediction; Unsupervised uses unlabeled data for pattern discovery.
*   **Semi-Supervised Utility:** It is used when labeling data is costly. It leverages a few labels to make sense of a large unlabeled dataset.
*   **Reinforcement Learning Mechanism:** It does not use static data in the traditional sense but relies on a dynamic feedback loop of "Rewards & Penalties" to learn "optimal actions."
*   **Goal Identification:** Be prepared to state the goal for each:
    *   Supervised -> Predict outputs.
    *   Unsupervised -> Find patterns.
    *   Semi-Supervised -> Improve learning (efficiency/accuracy with less labeled data).
    *   Reinforcement -> Learn optimal actions/policies.
