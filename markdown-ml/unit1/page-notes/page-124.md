## Math / Formula / Curve Notes
The slide presents two fundamental equations:

1.  **Simple Linear Regression Formula: $y = mx + c$**
    *   **$y$**: The dependent variable or the target value we are trying to predict.
    *   **$x$**: The independent variable or the single input feature.
    *   **$m$**: The slope of the line, representing the weight or coefficient of the input feature.
    *   **$c$**: The y-intercept, representing the constant value of $y$ when $x$ is zero.

2.  **Multiple Linear Regression Formula: $y = b_0 + b_1x_1 + b_2x_2 + ... + b_nx_n$**
    *   **$y$**: The dependent variable (output).
    *   **$b_0$**: The intercept or bias term (equivalent to '$c$' in the simple version).
    *   **$x_1, x_2, ..., x_n$**: Multiple independent variables or input features.
    *   **$b_1, b_2, ..., b_n$**: The coefficients (weights) assigned to each respective input feature, indicating their individual impact on the prediction.

## Concept Explanation
Regression is a supervised learning technique used to predict continuous numerical values (like price, temperature, or age).

*   **Linear Regression (Simple):** This model assumes a direct, linear relationship between one input variable and one output variable. Geometrically, this relationship is represented as a straight line on a 2D plane. It is used when you believe a single factor is the primary driver of the outcome.
*   **Multiple Linear Regression:** Real-world problems often involve many factors. This model extends simple linear regression by incorporating multiple input features ($x_1, x_2$, etc.). Instead of a line, it creates a "hyperplane" in a multi-dimensional space to find the best fit for the data points. It allows the model to account for the combined influence of various predictors.
