## Math / Formula / Curve Notes
The slide presents the population model for simple linear regression:
$$y = \beta_0 + \beta_1 x + \varepsilon$$

*   **$y$ (Dependent Variable):** The outcome or response variable that the model attempts to predict or explain.
*   **$x$ (Independent Variable):** The predictor or explanatory variable used to predict the value of $y$.
*   **$\beta_0$ (Beta Zero):** The y-intercept of the population regression line. It represents the expected value of $y$ when $x = 0$.
*   **$\beta_1$ (Beta One):** The slope of the population regression line. It represents the average change in $y$ for every one-unit increase in $x$.
*   **$\varepsilon$ (Epsilon):** The error term or residual. This represents the random variation in $y$ that is not explained by the linear relationship with $x$. In a population model, it accounts for all other factors affecting $y$ besides $x$.

## Concept Explanation
**Simple Linear Regression** is a statistical method used to model the relationship between a single independent variable ($x$) and a single dependent variable ($y$). 

The **Population Model** shown here is the theoretical "true" relationship that exists within an entire population. In practice, we rarely know the true values of $\beta_0$ and $\beta_1$, so we use sample data to estimate them. 

The inclusion of the **error term ($\varepsilon$)** is crucial. In the real world, data points rarely fall perfectly on a straight line. The error term acknowledges that the relationship is probabilistic rather than deterministic; it captures the "noise" or the influence of variables not included in the model.

## Exam / Viva Points
*   **Identify the Model:** Be able to write the population model equation: $y = \beta_0 + \beta_1 x + \varepsilon$.
*   **Define Parameters:** Clearly distinguish between $\beta_0$ (intercept) and $\beta_1$ (slope).
*   **Explain the Error Term:** Understand that $\varepsilon$ represents the difference between the actual observed value and the value predicted by the linear part of the model ($\beta_0 + \beta_1 x$).
*   **Variable Roles:** Know that $y$ is the dependent/response variable and $x$ is the independent/predictor variable.
*   **Population vs. Sample:** Recognize that this slide describes the *population* model (using Greek letters $\beta$), which differs from the *estimated sample* model (often using $b$ or $\hat{\beta}$).
