## Concept Explanation
**Data Preprocessing** is the "bridge" between raw data collection and model training. 
1.  **Cleaning:** This involves fixing "dirty" data, such as correcting typos, removing duplicate records, or dealing with impossible values (e.g., a negative age).
2.  **Transforming:** This involves changing the data's structure or scale. Examples include normalization (scaling numbers to a range like 0-1) or encoding (turning text categories like "Red/Blue" into numbers like "0/1").
3.  **Preparing:** This is the final packaging of data so the algorithm can ingest it, such as splitting data into training and testing sets.

The slide emphasizes that without these steps, a model will suffer from "Garbage In, Garbage Out" (GIGO), where poor data quality leads to poor predictions.

    *   To **format** data correctly (e.g., converting categorical text to numerical vectors).
*   **Outcome:** The ultimate goal is to improve **model accuracy** and **computational performance**.
