## Concept Explanation
*   **Supervised Learning:** This is a branch of machine learning where the model is trained on a "labeled" dataset. This means the algorithm is provided with both the input data (features) and the correct answers (targets) so it can learn the mapping between them.
*   **Regression vs. Classification:** While both are supervised learning, regression is specifically used when the target output is a **continuous number** (like 72.5 or $450,000). In contrast, classification is used for discrete categories (like "Cat" vs "Dog").
*   **Continuous Numerical Values:** These are values that can take any value within a range. For instance, a house price isn't just "expensive" or "cheap"; it is a specific dollar amount that can vary by even a single cent.
*   **Input Features:** These are the independent variables used to make a prediction. In the examples provided, "area" (square footage) and "time of year" are the features used to determine the price or temperature.

## Exam / Viva Points
*   **Definition to Memorize:** Regression is a supervised learning task where the goal is to predict a continuous numerical output based on one or more input features.
*   **Key Characteristic:** The output variable in regression is always quantitative/numerical and continuous.
*   **Common Examples:** 
    *   Real Estate: Predicting property value based on size, location, and age.
    *   Meteorology: Predicting exact temperature or rainfall amounts.
    *   Finance: Predicting stock prices or exchange rates.
*   **Distinction:** Be prepared to explain how regression differs from classification (continuous vs. categorical output).
