## Concept Explanation
The Machine Learning Pipeline is the systematic approach to solving problems using data.
*   **Problem Definition:** Understanding the business objective—what are we trying to predict or categorize?
*   **Data Collection:** Gathering raw data from databases, APIs, sensors, or web scraping.
*   **Data Cleaning & Preprocessing:** Fixing errors, handling missing values, and normalizing data so algorithms can process it.
*   **EDA:** Using statistics and visualizations to understand data distributions and relationships.
*   **Feature Engineering & Selection:** Creating new input variables (features) from raw data and picking the most impactful ones.
*   **Model Selection:** Choosing the best algorithm (e.g., Linear Regression, Neural Networks) for the specific task.
*   **Model Training:** The "learning" phase where the algorithm finds patterns in the training data.
*   **Model Evaluation and Tuning:** Checking the model's accuracy on a test set and adjusting "hyperparameters" to improve performance.
*   **Model Deployment:** Integrating the model into a real-world application (e.g., a website or app).
*   **Model Monitoring & Maintenance:** Checking if the model's performance degrades over time as real-world data changes (data drift).

## Exam / Viva Points
*   **Sequential Order:** Be able to list all 10 steps in the correct order.
*   **Iterative Nature:** Explain why it is a "lifecycle" (results from evaluation or monitoring often lead back to earlier steps like data cleaning or feature engineering).
*   **EDA vs. Feature Engineering:** Know the difference—EDA is for understanding; Feature Engineering is for creating better inputs for the model.
*   **Deployment vs. Monitoring:** Deployment is the act of "going live," while monitoring is the ongoing check to ensure the model stays accurate.
*   **Preprocessing Importance:** Why is step 03 critical? (Garbage in, garbage out—models only perform as well as the data they are fed).
