## Concept Explanation
**Modeling** is the central phase of the machine learning lifecycle. It is the act of applying a specific algorithm to a dataset to produce a "model."

1.  **The Input (Training Data):** The process starts with historical data where the answers or patterns are already known.
2.  **The Learning:** The algorithm analyzes this data to find underlying mathematical relationships, trends, or "patterns."
3.  **The Output (The Model):** The result of this process is the "model"—a functional representation of the learned patterns.
4.  **The Goal (Generalization):** The ultimate purpose of modeling is to take this trained model and apply it to "unseen data" (new data the model hasn't encountered before). Based on what it learned during training, the model can then provide a **prediction** (e.g., "This image is a cat") or a **decision** (e.g., "Deny this credit card transaction").

## Exam / Viva Points
*   **Definition:** Modeling is the process of building a machine learning model by extracting patterns from training data.
*   **Key Objective:** The primary goal is to enable the system to make accurate predictions or decisions on new, unseen data.
*   **Training vs. Inference:** Modeling happens during the "training" phase. Using the model on new data is called "inference."
*   **Keywords to remember:** Training data, patterns, machine learning model, unseen data, predictions, decisions.
