## Concept Explanation
Pattern recognition is the automated recognition of patterns and regularities in data. The slide divides this field into three core models:

1.  **Statistical Pattern Recognition:** This model is based on statistical characterizations of patterns. It assumes that patterns are generated by a probabilistic system. Features are extracted from the data and represented as points in a multi-dimensional feature space. Decision boundaries are then established using statistical tools (like Bayesian theory) to classify new data points.
2.  **Syntactic (Structural) Pattern Recognition:** This model is used when patterns have a clear hierarchical structure. It decomposes complex patterns into simpler sub-patterns called "primitives." It uses formal grammars and language theory to define the rules by which these primitives combine to form a valid pattern, much like how words form sentences in a language.
3.  **Neural Pattern Recognition:** This model utilizes Artificial Neural Networks (ANNs). It is inspired by the biological neural systems of the brain. Instead of explicit statistical rules or grammars, these models "learn" to recognize patterns by being exposed to large sets of training data, adjusting internal weights to map inputs to correct output classifications.

## Exam / Viva Points
*   **Identify the three models:** Be prepared to name Statistical, Syntactic, and Neural pattern recognition.
*   **Statistical PR Basis:** It relies on feature vectors and probability density functions.
*   **Syntactic PR Basis:** It relies on structural primitives and formal grammars (often called "Structural Pattern Recognition").
*   **Neural PR Basis:** It relies on parallel processing units (neurons) and learning algorithms like backpropagation.
*   **Comparison:** A common viva question is to compare these. For example, Statistical is good for quantitative data, while Syntactic is better for qualitative, structured data like character recognition or scene analysis.
