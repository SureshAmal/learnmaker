## Concept Explanation
*   **Discriminant Function:** In machine learning, this is a function that maps an input vector (features) to a specific class label. It acts as a decision-maker.
*   **Classification:** This is the task of predicting a discrete label for a given input. The discriminant function is the mathematical engine that performs this task.
*   **Feature Vector:** This is a numerical representation of the input data. For example, if you are classifying images of animals, the feature vector might contain values representing ear shape, tail length, and fur color.
*   **Function Values & Comparison:** The function calculates a score for the input. In multi-class classification, there might be a separate discriminant function for each class. The input is assigned to the class whose function yields the highest value. In binary classification, a single function might be used where the sign of the result (positive or negative) determines the class.

## Exam / Viva Points
*   **Definition:** A discriminant function is a mathematical tool used to partition a feature space into regions corresponding to different classes.
*   **Input:** It takes a **feature vector** as its primary input.
*   **Output/Action:** It produces a value (or set of values) that are compared to make a final **classification** decision.
*   **Context:** It is a core component in both **pattern recognition** (identifying regularities in data) and **machine learning** (building models that learn from data).
