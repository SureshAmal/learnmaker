The purpose of this slide is to introduce and define the fundamental vocabulary used in the field of pattern recognition. ## Visible Text
**Core concepts of pattern recognition :**

*   **Pattern:** Any measurable object, signal or data instance that contains identifiable characteristics.
*   **Feature:** A measurable property used to describe a pattern and distinguish between classes.
*   **Classifier:** A model or function that assigns class labels based on features.
*   **Decision Boundary:** The separating surface in feature space that divides different classes.
*   **Feature Space:** A multidimensional space where each pattern is represented as a vector of features.
*   **Training Data:** Labelled examples used to teach the model how to recognize patterns.

## Concept Explanation
This slide covers the lifecycle of a pattern recognition task:
1.  **Pattern:** This is the "thing" you want to identify (e.g., an image of a cat, a recording of a voice, or a medical record).
2.  **Feature:** Computers cannot "see" a cat; they see numbers. Features are the specific attributes extracted from the pattern (e.g., ear shape, color, frequency of sound) that help distinguish it from something else.
3.  **Feature Space:** If you have two features (height and weight), you can plot them on an X-Y graph. This graph is the "Feature Space." If you have $N$ features, it becomes an $N$-dimensional space.
4.  **Classifier:** This is the "brain" or the mathematical function. It looks at the features of a new, unknown pattern and decides which category it belongs to.
5.  **Decision Boundary:** Imagine a scatter plot of red dots and blue dots. The line you draw to separate them is the decision boundary. The classifier's job is to find the best possible boundary.
6.  **Training Data:** This is the "study material." It consists of patterns where we already know the answer (labels). The classifier looks at these to learn where the decision boundaries should be placed.

## Exam / Viva Points
*   **Definition of a Pattern:** Be ready to define it as a "measurable object" with "identifiable characteristics."
*   **Feature vs. Pattern:** A pattern is the whole object; a feature is a specific, measurable attribute of that object.
*   **Feature Space Representation:** Understand that in a feature space, every pattern is treated as a **vector**.
*   **Role of the Classifier:** It is a function that maps features to class labels.
*   **Decision Boundary:** It is a "surface" (or line/hyperplane) that separates different classes in the feature space.
*   **Training Data:** Must be "labelled" to be used for supervised learning in pattern recognition.
