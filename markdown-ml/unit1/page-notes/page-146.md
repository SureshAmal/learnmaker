## Concept Explanation
The slide introduces two major concepts:

1.  **The Goal of Machine Learning:** It defines ML not just as data processing, but as a way to enable machines to emulate human cognitive functions—specifically "thinking" and "understanding." The mechanism for achieving this is "learning from data," which distinguishes ML from traditional rule-based programming where every step is explicitly defined by a human.
2.  **Taxonomy of Learning:** It categorizes how machines learn into several paradigms:
    *   **Supervised Learning:** The model learns from labeled data (input-output pairs).
    *   **Unsupervised Learning:** The model finds hidden patterns or structures in unlabeled data.
    *   **Reinforcement Learning:** An agent learns to make decisions by performing actions in an environment to maximize a cumulative reward.
    *   **Semi-Supervised Learning:** A hybrid approach using a small amount of labeled data combined with a large amount of unlabeled data.
    *   **Self-Supervised Learning:** A form of unsupervised learning where the system generates its own labels from the data (e.g., predicting a missing part of an image or the next word in a sentence).

*Note: While the slide mentions "three core types," it lists five. Traditionally, Supervised, Unsupervised, and Reinforcement are considered the three primary pillars, while the others are specialized extensions.*
