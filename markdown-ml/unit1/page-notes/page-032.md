## Concept Explanation
This slide covers the "Garbage In, Garbage Out" principle of machine learning.
*   **Messy Data:** Real-world data is rarely perfect. It may have missing entries (e.g., a user didn't fill out their age), outliers (e.g., a height recorded as 10 feet due to a typo), or inconsistencies (e.g., "USA" vs "United States").
*   **Data Cleaning:** This is the act of "fixing" the data. This involves deciding how to handle missing values (deleting them or filling them in) and identifying/removing errors.
*   **Data Preprocessing:** This involves transforming data into a format the algorithm can process efficiently. 
    *   **Scaling:** Ensuring all numerical features are on a similar scale (e.g., 0 to 1) so one feature doesn't dominate others.
    *   **Encoding:** Converting text categories (like "Red", "Blue") into numbers that the computer can perform math on.
*   **Data Quality:** The end goal is to have a structured, reliable dataset that allows the model to find true patterns rather than learning from noise or errors.

## Exam / Viva Points
*   **Why is raw data not used directly for training?** Because it is often messy and unstructured, leading to poor model accuracy.
*   **What are the three main tasks in Data Cleaning?** Addressing missing values, handling outliers, and fixing inconsistencies.
*   **What does Data Preprocessing involve?** Standardizing formats, scaling numerical values, and encoding categorical variables.
*   **Define "Encoding" in this context:** The process of converting non-numeric (categorical) data into a numeric format suitable for machine learning algorithms.
*   **What is the ultimate goal of Step 3?** To ensure high data quality so the data is prepared for meaningful analysis and effective model training.
