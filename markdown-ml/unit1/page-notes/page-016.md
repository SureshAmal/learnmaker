## Concept Explanation
*   **Unsupervised Learning:** Unlike supervised learning, where the model is given "answers" (labels) to learn from, unsupervised learning involves feeding the model raw data without any target labels. The model must find its own way to organize the information.
*   **Unlabeled Data:** Data that contains input features (e.g., height, weight, age) but lacks a specific outcome or category label (e.g., "Healthy" vs. "Sick").
*   **Goal:** The primary aim is to find the underlying structure of the data. This could mean grouping similar items together (Clustering), finding rules that describe the data (Association), or simplifying the data (Dimensionality Reduction).
*   **Key Algorithms Mentioned:**
    *   **K-Means & Hierarchical Clustering:** Methods to group data points into clusters based on similarity.
    *   **DBSCAN:** A density-based clustering algorithm that can find clusters of arbitrary shapes and identify noise/outliers.
    *   **PCA:** A technique used to reduce the number of variables in a dataset while keeping as much information as possible.
    *   **Apriori:** An algorithm used for association rule mining, often used in market basket analysis to find items frequently bought together.
