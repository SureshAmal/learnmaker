## Concept Explanation
*   **Feature:** In machine learning, a feature is an individual measurable property or characteristic of a phenomenon being observed. Features are the "input variables" used by a model to make predictions.
*   **Flower Classification (Iris Dataset):** This is a foundational example in machine learning. To distinguish between different species of flowers (e.g., Iris Setosa, Versicolor, and Virginica), we need data.
*   **Numerical Features:** The slide highlights that these features are "numerical values." In ML, numerical data is preferred because mathematical algorithms can easily perform operations on them (like calculating distances or finding patterns in a multi-dimensional space). These specific features are continuous variables, meaning they can take any value within a range (e.g., 5.1 cm, 3.5 cm).
