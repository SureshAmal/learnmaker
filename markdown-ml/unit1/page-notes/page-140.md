## Concept Explanation
Discriminant functions are a fundamental tool in supervised machine learning, specifically for **classification**. A discriminant function takes an input vector (features) and maps it to a specific class label. It essentially defines the "decision boundaries" that separate different classes in the feature space.

The applications listed represent classic classification problems:
*   **Face Recognition:** The system must discriminate between different human faces. The function analyzes facial features to determine which specific identity (class) the input image belongs to.
*   **Handwriting Digit Recognition:** This is a multi-class classification problem (classes 0-9). The discriminant function identifies patterns in pixel data to categorize a handwritten shape as a specific digit.
*   **Medical Diagnosis:** Often a binary classification (e.g., "Disease Present" vs. "Disease Absent"). The function uses patient data (symptoms, test results) to decide which category is most likely.
*   **Spam Detection:** A binary classification task where the function analyzes email content and metadata to discriminate between "Spam" and "Ham" (legitimate email).
