## Concept Explanation
A **Decision Surface** is a fundamental concept in supervised classification. 
*   **Feature Space:** Imagine a graph where each axis represents a feature (e.g., height and weight). This is the "input feature space."
*   **Partitioning:** When a machine learning model is "fit" (trained) on data, it learns a rule to distinguish between different classes (e.g., "Cat" vs. "Dog").
*   **The Surface:** The decision surface is the boundary (a line in 2D, a plane in 3D, or a hyperplane in higher dimensions) that the model creates to separate these classes. 
*   **Visualization:** By plotting this surface, researchers can see if a model is simple (linear boundary) or complex (wiggly, non-linear boundary). It helps in identifying if a model is overfitting (creating overly complex boundaries to catch every outlier) or underfitting (using a boundary that is too simple to capture the data's pattern).

## Exam / Viva Points
*   **Definition:** A decision surface is a visual representation (plot) of how a trained model partitions the feature space into regions assigned to specific class labels.
*   **Utility:** It is used to visualize the "logic" of a model's predictions and understand the complexity of the learned decision boundaries.
*   **Dimensionality:** While we usually visualize them in 2D or 3D, decision surfaces exist in $N$-dimensional space where $N$ is the number of input features.
*   **Model Comparison:** Different algorithms produce different surfaces. For example, a Logistic Regression model produces a linear decision surface, while a Random Forest or RBF SVM produces non-linear, often complex surfaces.
