## Concept Explanation
**Reinforcement Learning (RL)** is a paradigm of machine learning inspired by behavioral psychology. Unlike Supervised Learning (which uses labeled data) or Unsupervised Learning (which finds hidden patterns), RL is about **learning from interaction**.

*   **The Core Loop:** An **Agent** (the AI) exists within an **Environment**. At any given time, the environment is in a specific **State**. The agent looks at the state and chooses an **Action** based on its **Policy** (its internal strategy).
*   **Feedback Mechanism:** After performing the action, the environment changes to a new state and provides the agent with a **Reward** (a numerical value). If the action was good, the reward is positive; if bad, it's a penalty (negative reward).
*   **The Objective:** The agent's ultimate goal is not just to get a high reward for the current step, but to maximize the **cumulative reward** (total reward) over a long period. Through trial and error, the agent refines its policy to make better decisions in the future.

## Exam / Viva Points
*   **Definition of RL:** A type of ML where an agent learns optimal behavior through trial-and-error interaction with an environment to maximize cumulative rewards.
*   **The Goal:** The primary objective of an RL agent is to maximize the **total reward over time**, not just the immediate reward.
*   **Key Components to Memorize:**
    1.  **Agent:** The entity making decisions.
    2.  **Environment:** The external system the agent interacts with.
    3.  **State ($S$):** The current "snapshot" or configuration of the environment.
    4.  **Action ($A$):** The choices available to the agent.
    5.  **Reward ($R$):** The feedback signal (scalar value).
    6.  **Policy ($\pi$):** The mapping from states to actions (the agent's strategy).
*   **Distinction:** Be prepared to explain how RL differs from Supervised Learning (RL lacks a "teacher" providing correct answers; it only has a reward signal that may be delayed).
