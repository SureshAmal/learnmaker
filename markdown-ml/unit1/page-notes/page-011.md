## Concept Explanation
**Supervised Learning** is a type of machine learning where the model is trained using a "labeled" dataset. 
*   **Labeled Data:** This means that for every piece of input data provided to the algorithm during training, the correct answer (the "label" or "target") is also provided. 
*   **The "Supervisor":** You can think of the labeled data as a teacher or supervisor. The algorithm makes a prediction based on the input, compares it to the known correct output, and adjusts its internal parameters to minimize the error.
*   **Goal:** The ultimate goal is for the algorithm to learn a general rule or mapping function ($Y = f(X)$) that allows it to accurately predict the output ($Y$) for new, unseen input data ($X$).

The slide lists five key algorithms:
1.  **Linear Regression:** Used for predicting continuous numerical values (e.g., house prices).
2.  **Logistic Regression:** Despite the name, it's used for classification tasks (e.g., determining if an email is spam or not).
3.  **Decision Trees:** A flowchart-like structure used for both classification and regression.
4.  **Support Vector Machines (SVM):** Effective for high-dimensional data, often used for complex classification.
5.  **Neural Networks:** Computational models inspired by the human brain, capable of learning very complex patterns in large datasets.

## Exam / Viva Points
*   **Define Supervised Learning:** It is a learning process where the model is trained on a dataset containing both inputs and their corresponding correct outputs (labels).
*   **Key Characteristic:** The presence of a "ground truth" or known output for every training example.
*   **Identify Algorithms:** Be prepared to name at least three supervised learning algorithms (e.g., Linear Regression, SVM, Decision Trees).
*   **Contrast (Implicit):** Understand that supervised learning differs from unsupervised learning, where the data has no labels and the algorithm must find patterns on its own.
*   **Application:** Supervised learning is typically used for two types of problems: **Regression** (predicting a quantity) and **Classification** (predicting a category).
