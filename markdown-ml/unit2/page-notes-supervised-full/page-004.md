## Concept Explanation
Regression is a fundamental supervised learning task where the goal is to predict a continuous numerical output (the dependent variable) based on one or more input features (independent variables/predictors).

The slide explains that these algorithms are categorized by:
1.  **Number of Predictors:** 
    *   **Simple:** Only one independent variable is used to predict the outcome.
    *   **Multiple:** Two or more independent variables are used.
2.  **Nature of Relationship:**
    *   **Linear:** Assumes a straight-line relationship between inputs and outputs.
    *   **Non-Linear:** Includes Polynomial, Decision Trees, and Random Forests, which can model complex, curved, or segmented relationships.
    *   **Regularized:** Ridge and Lasso are techniques used to prevent "overfitting" by adding a penalty to the size of coefficients.
    *   **Algorithmic variations:** Support Vector Regression (SVR) uses the principles of Support Vector Machines to find a fit within a specific error margin (epsilon).

## Exam / Viva Points
*   **Classification Criteria:** Be prepared to state that regression is classified based on the **number of predictors** and the **nature of the relationship** (linear vs. non-linear).
*   **List of Types:** You should be able to name at least five of the seven types listed (Simple Linear, Multiple Linear, Polynomial, Ridge/Lasso, SVR, Decision Tree, Random Forest).
*   **Simple vs. Multiple:** Know the basic distinction: Simple = 1 predictor; Multiple = >1 predictor.
*   **Regularization:** If asked about Ridge and Lasso, mention they are used to handle multicollinearity and prevent overfitting in linear models.
*   **Ensemble Methods:** Note that Random Forest Regression is an "ensemble" method, meaning it combines multiple decision trees to improve prediction accuracy.
