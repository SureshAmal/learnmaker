## Concept Explanation
*   **Regression:** A fundamental statistical method used to model the relationship between variables. It is "predictive" because once a relationship is established, the model can be used to forecast future or unknown values.
*   **Dependent Variable ($Y$):** Also known as the "target" or "outcome." This is the specific value the model is trying to predict (e.g., the price of a house).
*   **Independent Variable ($X$):** Also known as "predictors" or "features." These are the input factors that are believed to influence the dependent variable (e.g., the square footage or location of a house).
*   **Relationship Estimation:** Regression calculates how much the dependent variable changes when one or more independent variables change.

## Exam / Viva Points
*   **Definition:** Regression is a predictive modeling technique used to estimate the relationship between variables.
*   **Variables:** A student must distinguish between the **dependent variable** (the outcome/target) and **independent variables** (the factors/predictors).
*   **Context:** It is a primary tool used in both classical statistics and modern data science for predictive analysis.
*   **Goal:** The primary goal is to understand how the typical value of the dependent variable changes when any one of the independent variables is varied.
