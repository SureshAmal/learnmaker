## Concept Explanation
*   **Linear Regression:** A supervised learning algorithm used to predict a continuous numerical output based on one or more input features.
*   **Independent Variable (Input):** The variable that is changed or controlled in a scientific experiment to test the effects on the dependent variable. In ML, this is the feature $x$.
*   **Dependent Variable (Output):** The variable being tested and measured. In ML, this is the target $y$ we want to predict.
*   **Best Fit Line:** Because real-world data is rarely perfectly aligned, we draw a straight line through the scatter plot of data points. The "best" line is the one that has the least total distance from all the points combined.
*   **Minimization Goal:** This refers to reducing the "Residuals" or "Error." The model calculates the vertical distance between an actual data point ($y$) and the point on the line directly above or below it ($\hat{y}$). The most common method to achieve this is **Ordinary Least Squares (OLS)**, which minimizes the sum of the squares of these differences.
