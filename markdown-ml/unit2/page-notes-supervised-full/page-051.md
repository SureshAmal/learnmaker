## Math / Formula / Curve Notes
The central formula is: **$\sum(y_i - \hat{y}_i)^2$**
*   **$\sum$ (Sigma):** The summation symbol, indicating that we add up the results for every data point in the dataset (from $i=1$ to $n$).
*   **$y_i$:** Represents the **actual value** (ground truth) of the dependent variable for the $i$-th observation.
*   **$\hat{y}_i$ (y-hat):** Represents the **predicted value** generated by the regression line equation (e.g., $mx_i + b$) for the same $i$-th observation.
*   **$(y_i - \hat{y}_i)$:** This is the **residual** or error. It measures the vertical distance between the actual data point and the regression line.
*   **$^2$ (Square):** The residuals are squared for two main reasons:
    1.  To ensure all error values are positive (so positive and negative errors don't cancel each other out).
    2.  To penalize larger errors more heavily than smaller ones.

## Concept Explanation
The **Least Squares Method** is the standard way to find the "best-fit" line in linear regression. 

In any dataset, the data points rarely fall perfectly on a straight line. When we draw a line to represent the data, there will be "errors" (residuals) between the line and the actual points. The Least Squares Method provides a mathematical way to choose the line that is "closest" to all points simultaneously.

By calculating the square of every error and then summing them all up, we get a single number representing the total error of that specific line. The "best" line is the one that results in the **minimum possible value** for this sum. This ensures the model has the highest possible accuracy across the entire dataset.

## Exam / Viva Points
*   **What does $y_i$ represent?** It is the actual observed value from the dataset.
*   **What does $\hat{y}_i$ represent?** It is the predicted value calculated by the regression model.
*   **Define a "Residual":** The difference between the actual value and the predicted value ($y_i - \hat{y}_i$).
*   **What is the objective of the Least Squares Method?** To minimize the sum of the squared residuals.
*   **Why do we square the residuals?** To prevent positive and negative errors from canceling each other out and to give more weight (penalty) to larger outliers.
*   **What is the resulting line called?** The "Line of Best Fit."
