## Math / Formula / Curve Notes
*   **Formula:** $Residual = y_i - \hat{y}_i$
*   **$y_i$ (Actual Value):** Represents the observed value of the dependent variable for the $i$-th observation in the dataset.
*   **$\hat{y}_i$ (Predicted Value, pronounced "y-hat"):** Represents the value predicted by the linear regression model for the $i$-th observation.
*   **Interpretation:** The residual is the vertical distance between a data point and the regression line. A positive residual means the actual value is above the line; a negative residual means it is below. The Least Squares Method aims to minimize the sum of the squares of these residuals.

## Concept Explanation
*   **Least Squares Method:** In linear regression, we want to find a line that represents the data as accurately as possible. The "Least Squares" approach does this by finding the line where the sum of the squares of the vertical deviations (residuals) between each data point and the line is minimized. Squaring the residuals ensures that positive and negative errors don't cancel each other out and gives more weight to larger errors.
*   **Residuals:** A residual is essentially the "error" of the model for a single data point. It is the difference between what actually happened ($y_i$) and what the model predicted would happen ($\hat{y}_i$). By analyzing residuals, data scientists can determine how well a model fits the data.

## Exam / Viva Points
*   **Definition of Residual:** It is the difference between the actual observed value ($y_i$) and the predicted value ($\hat{y}_i$).
*   **Purpose of Least Squares:** It is the optimization strategy used to find the best-fit line by minimizing the total error (sum of squared residuals).
*   **Formula to Remember:** $Residual = y_i - \hat{y}_i$.
*   **Significance of "Squares":** Squaring the residuals prevents positive and negative errors from canceling each other out and penalizes larger outliers more heavily.
