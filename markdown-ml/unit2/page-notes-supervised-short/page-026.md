## Concept Explanation
*   **Variance:** In the context of the Bias-Variance tradeoff, variance refers to the amount that the estimate of the target function will change if different training data was used. 
*   **Noise vs. Signal:** "Signal" is the true underlying pattern in the data that we want the model to learn. "Noise" consists of random fluctuations, errors, or outliers that do not represent the true pattern.
*   **Overfitting:** This occurs when a model is too complex (high variance). It "memorizes" the training data, including its noise, instead of "learning" the general pattern. 
*   **Generalization:** The goal of machine learning is for a model to perform well on data it has never seen before. High variance prevents this because the model is too specific to its original training set.
*   **Analogy:** The "hyper-active puppy" analogy illustrates a model that is easily distracted by every individual data point (the noise) instead of following the overall trend (the signal).

## Exam / Viva Points
*   **Definition of Variance:** It is the model's sensitivity to small fluctuations in the training set.
*   **The core problem of high variance:** The model learns the "noise" instead of the "signal."
*   **Consequence:** High variance leads to **Overfitting**.
*   **Performance Characteristics:** An overfitted model shows very high accuracy on training data but very low accuracy (fails) on test/unseen data.
*   **Visual Description:** If plotted, high variance looks like a highly complex, "wiggly" line that tries to touch every single data point.
